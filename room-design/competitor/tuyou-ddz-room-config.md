## 与我们的七档方案对比

### 底分量级

| | 我们 | 途游 |
| --: | --: | :--- |
| 最低档 | 30 | **2,000**（67×） |
| 最高档 | 5,000 | **50 万**（100×） |
| 档位数 | 7 | 4 |

途游底分整体高 1-2 个数量级，分量碾压。

### 入场门槛（下限/底分）

| 档位 | 我们 | 途游 |
| --: | --: | --: |
| 入门 | 1,000 / 30 = **33×** | 10 万 / 2,000 = **50×** |
| 第二档 | 3,000 / 100 = **30×** | 80 万 / 1 万 = **80×** |
| 第三档 | 30,000 / 500 = **60×** | 800 万 / 6 万 = **133×** |
| 最高档 | 50 万 / 5,000 = **100×** | 5,000 万 / 50 万 = **100×** |

途游从第二档起门槛比例远高于我们，筛人更激进。

### 费率（修正）

途游 #2-#4 固定叫分 15，实际底分 = 名义 × 15，实际费/底分远低于名义值：

| 档位 | 我们（实际） | 途游 名义 | 途游 **实际** |
| --: | --: | --: | --: |
| 入门 | 1.33× | 5.0× | —（正常叫分，不适用） |
| 第二档 | 1.5× | 5.0× | **0.33×** |
| 第三档 | 1.5× | 8.3× | **0.56×** |
| 最高档 | 1.5× | **10.0×** | **0.67×** |

**途游实际费率比我们低**（0.33-0.67× vs 1.5×），尽管名义值看着高 3-7 倍。固定叫分 15 摊薄了服务费占比——本质是把"费率分母"做大了 15 倍。费率随档位递增，但最高才到我们的一半。

### 封顶机制

途游全档位有单局赔付封顶：

| 档位 | 封顶 | 折合倍数（封顶/底分） |
| --: | --: | --: |
| 新手桌 | 5,000 万 | **25,000×** |
| 练习桌 | 2,000 万 | **2,000×** |
| 牌友桌 | 3 亿 | **5,000×** |
| 大师桌 | 25 亿 | **5,000×** |

封顶倍数极高（2000-5000×），对绝大多数对局不构成限制（我们 192+ 仅占 ~2%），实际作用是防极端异常值。

### 叫分机制

途游 #2-#4 **无叫分，默认 15 分**。这意味着：
- 地主固定 15 分叫分，没有抢地主叫分环节
- 倍数链少了叫分这一层变数，理论倍数分布会更集中（可能集中在 15 的倍数附近）
- #1 新手桌仍保留正常叫分

### 核心差异总结

| 维度 | 我们 | 途游 |
| :--- | :--- | :--- |
| 底分量级 | 30-5,000 | 2,000-50 万（高 1-2 个数量级） |
| 档位数 | 7 档精细分层 | 4 档 |
| 费率 | 1.5× 恒定 | 名义 5-10×，**实际 0.33-0.67×**（叫分 15 摊薄） |
| 叫分 | 全档位正常叫分 | 仅新手桌叫分，其余固定 15 分 |
| 封顶 | 无 | 2000-5000× 封顶 |
| 目标用户 | 大众全阶层 | 高净值（入门即 10 万携银） |

途游是**超高分量 + 低费率**路线。门槛极高（入门即 10 万下限）、底分量级大我们 1-2 个数量级，但固定叫分 15 把实际费率压到 0.33-0.67×（比我们 1.5× 还低）。无叫分简化了倍数链，封顶兜底风控。与我们"低底分 + 精细分层 + 恒定费率"是两种完全不同的模型。
