# 经典斗地主房间设计 — 分析框架

## 核心概念

### 1. 理论倍数 vs 实际倍数

- **理论倍数**（`magnification`）：由叫分、炸弹、加倍等倍率链的完整乘积，代表「理论上该输赢多少倍底分」
- **实际倍数**（`real_magnification`）：`ABS(game_outcome_money) / room_base`，代表「实际发生的输赢除以底分」

当理论倍数 > 玩家余额能支付的金额时，发生**破产截断**——实际倍数 < 理论倍数。

### 2. 兑现率（Realization Rate）

```
兑现率 = AVG(real_magnification) / AVG(magnification)
```

取值范围 0~1。1.0 表示理论倍数完全兑现，越低说明破产截断越严重。目标 ≥ 0.80。

### 3. 扛倍数（Affordable Magnification）

玩家余额能承受的最大倍数，超过即发生破产截断：

```
地主扛 = (携银 − 服务费) / (2 × 底分)    ← 瓶颈（需付 2 个农民）
农民扛 = (携银 − 服务费) / 底分          = 2 × 地主扛
```

### 4. 房间区间

每个房间的扛下限和扛上限定义一个「安全区间」：

```
区间 = [扛下限, 扛上限]
```

- 扛下限：按下限携银进场的玩家最少能扛的倍数 → 安全感
- 扛上限：按上限携银进场的玩家最多能扛的倍数 → 天花板

### 5. 服务费率

```
Vavg = 底分 × 农民平均倍数 × 三斗系数(1.0~1.33)
费率 = 服务费 / Vavg
```

目标 6-12%，等级越高费率越高。

---

## 设计原则

| # | 原则 | 说明 |
| --- | --- | --- |
| 1 | 升级有感 | 每升一级，扛下限或扛上限至少跳一档（12/24/48/96/192/∞） |
| 2 | 安全垫 | 扛下限 ≥ 区间下限 × 1.2（20% 缓冲，避免零容错） |
| 3 | 上限不锁死 | 扛上限 > P80扛，玩家存款不被结构天花板限制 |
| 4 | 费率递增 | 等级越高费率越高（更好服务 = 更高费用） |
| 5 | 最小改动 | 优先修正灾难参数，健康房间尽量不动 |

---

## 执行优先级

```
高等级优先（影响面小、改动安全）
→ 放上限（零伤害）
→ 降底分（需观察）
→ 微调下限
→ 低等级保持现状
```

- P50/P80 余额：各房间玩家 `MAX(start_money)` 分位数
- 理论倍数分布：全量地主对局的 `magnification` 分位数
