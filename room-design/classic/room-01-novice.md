# 房间 #1 — 新手场

## 定位

新玩家注册后的教学过渡场。配牌护送，几局后毕业进入 #2 初级场正式开始竞技。

## 参数

| 项目 | 值 |
| ---- | ---- |
| 底分（room_base） | 30 |
| 入场下限（room_currency_lower） | 1,000 |
| 入场上限（room_currency_upper） | 3,000 |
| 服务费（room_fee） | 40 |
| 区间 | **[12×, 48×]** |

## 核心指标

| 指标 | 值 | 说明 |
| ---- | ---- | ---- |
| 地主扛下限 | 16.0× | 带 1,000 进场，最少能扛 16 倍 |
| 地主 P50 扛 | 38.3× | 中位玩家（携银 2,340）覆盖 P75 理论 |
| 地主 P80 扛 | 40.5× | |
| 农民扛下限 | 32.0× | = 地主 × 2 |
| 农民 P50 扛 | 76.7× | |
| 农民 P80 扛 | 81.0× | |
| 地主扛上限 | 49.3× | 覆盖 48× |
| 费率 | 6.1% | 40 / (30 × 21.7) |

## 区间覆盖

```
下限扛 16.0× → 覆盖 12×（P35-P50 理论）
P50 扛 38.3× → 覆盖 24×（P75 理论）
扛上限 49.3× → 覆盖 48×（P85 理论）
```

## 设计推导

- 底分 30：与旧 742 房间一致，玩家行为验证过
- 下限 1,000：零门槛，注册就能进
- 上限 3,000：覆盖 48× 足够。新手场不需要更高天花板
- 费率 6.1%：入门档最低费率
