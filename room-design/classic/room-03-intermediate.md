# 房间 #3 — 中级场

## 定位

有一定积蓄的玩家，底分提升到 400，下限覆盖 12×——进入即有安全感。

对应线上房间：**6314**（底分 500）。

| 项目 | 当前值 | **调整值** |

| 底分（room_base） | 500 | **400** |

| 服务费（room_fee） | 750 | **600** |

## 区间覆盖

```
扛下限 14.3× → 覆盖 12×（P50 理论）✓
P50 扛 22.9× → 覆盖 12×，接近 24×
P80 扛 38.7× → 覆盖 24×（P75 理论）
扛上限 74.3× → 覆盖 48×（P85 理论）
```

## 设计推导

- 底分 500→400：为 #4（底分 600）让出层级空间
- 下限 6,000→1.2 万：P25 玩家余额 ~8,700，1.2 万筛掉约 25%，但换来扛下限从 5.6× 跳到 14.3×——100% 的提升
- 上限 5 万→6 万：配合底分调降，维持 48× 覆盖
- 费率不变：底分降了，但服务费同比例降，费率持平

## 改动说明

| 参数 | 改动 | 幅度 | 风险 |
| ---- | ---- | :---: | :--- |
| 底分 | 500 → 400 | −20% | 低 |

| 上限 | 5 万 → 6 万 | +20% | 低 |
| 服务费 | 750 → 600 | −20% | 低 |
