# 房间 #7 — 巅峰场

## 定位

金字塔尖，超顶级高净值玩家主战场。承接 #6 的 50万+ 高携银玩家，保地主 **M48 零截断**（比 #6 的 M24 更高一档）。

> **新建房间**（线上无），基于 #6 现状（底分 4000）50万+ 地主数据模拟。倍数分布沿用 #6（纯 2M）。
> 数据源：`tcy_temp.dws_ddz_daily_game`，`game_id=53 AND play_mode=1 AND robot!=1 AND room_base=4000 AND start_money>=500000`（#6 高携银地主）+ 底分 5000 需付模拟，2026-06-15 ~ 2026-07-14。

## 参数设计

### 底分：5,000

#7 作为金字塔尖，分量（绝对金额）是核心商品。底分 5000，M48 赔付 = 96×5000 = 48 万（大额兑现）。玩家携银 50 万+，扛得住高倍。

### 入场下限：50 万

承接 #6 的 50 万+ 地主（占 #6 的 38%）。底分 5000 下：
- M48 需付 = 96×5000+7500 = 48.75 万 < 50 万 → **M48 零截断**（margin 0.25 万）
- 扛下限 = (50万 − 7500) / (2×5000) = **49.25×**（保 M48）

> **Margin 提示**：M48 需付 48.75 万 vs 下限 50 万，margin 0.25 万（紧）。逻辑零截断成立（地主携银 ≥50 万 > 48.75 万）。若求安全可下限 60 万（margin 11.25 万），但池子更小。

### 入场上限：∞

顶层无上限，超高净值玩家不受结构天花板限制。

### 服务费：7,500

`fee = 1.5×底分 = 7500`（M12 体感线）。农民体感（底分 5000）：M12 赢 6 万 抽 12.5%（达标）；M3 赢 1.5 万 抽 50%（固定 fee 固有缺陷）。费率 = 7500 / Vavg(5000×~14) ≈ 10.7%。

## 截断（携银下界，底分 5000）

地主需付 = `mag×5000+7500`（地主 mag=2M）。

| 游戏倍数 | 需付 | **#7 截断** |
| ---- | ---: | ---: |
| M24 | 24.75 万 | 0% |
| M48 | 48.75 万 | **0%** |
| M96 | 96.75 万 | 56.4% |
| M192 | 192.75 万 | 76.5% |

> **M48 零截断是 #7 的核心价值**（#6 只保 M24）。M48 局（占 4.2%）从 #6 的截断状态变成 #7 的足额兑现。M96+ 仍有截断（玩家携银 50-96 万），属超高端局。
