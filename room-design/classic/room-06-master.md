| ---- | ---- | ---: | ---: |
| 农民 | 2/3 | 9.8× | 39,200 银子 ≈ 3.9 元 |
| 地主 | 1/3 | 18.9× | 75,600 银子 ≈ 7.6 元 |
| **加权均值** | | | **51,300 银子 ≈ 5.1 元** |

加权 = (2/3)×39,200 + (1/3)×75,600 = **51,300 银子 ≈ 5.1 元**（excl 192×+；含 192×+ 因重度截断略低）。

> 这是 #6 的"体量锚点"。降底分会等比缩水这个数（4,000 → 2,500 时 5.1 元 → 3.2 元），倍数形状不变——正是"底分 = 分量"的直观数量化。

## 设计推导

### 倍数是"形状"，底分是"分量"

倍数阶梯（3/6/12/24/48…）是游戏机制定的，**全房间相同**——#2 的玩家和 #6 的玩家打出的倍数分布形状几乎一致。真正区分房间档次的，是底分把每个倍数翻译成多少银子：

| 同一个 48× | 底分 | 绝对金额 |
| ---- | ---: | ---: |
| #2（250 底分） | 250 | 1.2 万 |
| #6（4,000 底分） | 4,000 | 19.2 万 |

顶级房卖的就是"分量"——鲸鱼来 #6 是为 48× = 19.2 万的绝对金额，不是为"48 倍"这个数字。降底分保住倍数体验（形状不变），但分量等比缩水，等于把核心商品打折。

### 两条杠杆都被堵死

| 杠杆 | 后果 |
| ---- | ---- |
| 提下限（→ 40 万确保 48×） | 筛掉 ~80% 玩家（P75 最高携银仅 33.9 万，进不来） |
| 降底分（→ 2,500） | 分量 −37.5%，但平均实际倍数仅 +2%（84% 的局 ≤24× 截断率本就很低：≤12× 零、24× 地主 21%/农民 0%，降底分受益面有限） |

要"48× 确保"的真 apex，只剩第三个动作：**新建 #7**——用 40 万下限管"谁能进来"，用保持 4,000+ 底分保住"分量"，两个职能拆到两个房间。

### 结论

- **不动**：P50扛 24.5× → 兑现率 0.91，七档中最健康
- 无上限天花板，玩家想带多少带多少
- 服务费率 14.6% 偏高（超出 6-12% 目标），但作为顶级房可接受
- 48× 截断集中在 P25 以下低余额玩家——属于软性筛选，不必干预
