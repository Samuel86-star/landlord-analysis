# 房间 #2 — 初级场

## 定位

新手毕业后的第一个竞技房间。玩家从 #1 晋升后在此正式开始对局。

对应线上房间：**4484 / 12074**（底分 250）。

| 项目 | 值 |
| ---- | ---- |
| 底分（room_base） | 250 |

| 入场上限（room_currency_upper） | 3 万 |
| 服务费（room_fee） | 350 |
| 区间 | **[—, 48×]** |

## 区间覆盖

```
扛下限 5.3×  → 未达 12×（当前弱点）
P50 扛 21.9× → 覆盖 12×（P50 理论）
P80 扛 37.0× → 覆盖 24×（P75 理论）
扛上限 59.3× → 覆盖 48×（P85 理论）
```

## 设计推导

- **暂不动**：12 万玩家在此房，任何参数变动影响巨大
- 扛下限 5.3× 是底分 250 / 下限 3,000 的历史遗留——要提到 12× 需下限 ≥ 6,350，筛掉约 40% 玩家
- 当前兑现率 0.50（去极端值 0.72），在入门级可接受
- 待 #3-#6 调整稳定后，再根据数据决定是否优化此房
