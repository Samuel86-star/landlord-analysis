# 房间 #4 — 进阶级

## 定位

**本次调整的重点房间。** 当前线上 1,200 底分房 P50 扛仅 11.5×、兑现率 0.59，是对局体验最差的房间。降底分翻倍增 P50 扛，天花板从 96× 打开。

对应线上房间：**11168**（底分 1,200）。

## 参数

| 项目 | 当前值 | **调整值** |
| ---- | ---- | ---- |
| 底分（room_base） | 1,200 | **600** |
| 入场下限（room_currency_lower） | 1.5 万 | **2.5 万** |
| 入场上限（room_currency_upper） | 12 万 | **20 万** |
| 服务费（room_fee） | 1,800 | **900** |
| 区间 | — | **[12×, 96×]** |

## 区间覆盖

```
扛下限 20.1×  → 覆盖 12×（P50 理论）✓（+247%）
P50 扛 23.7×  → 覆盖 12×，接近 24×（+106%）
P80 扛 52.0×  → 覆盖 48×（P85 理论）
扛上限 165.9× → 覆盖 96×（P90+理论）
```

## 设计推导

- **底分 1,200→600**：核心手术。当前 1,200 底分房 P50 玩家余额 2.9 万，只够扛 11.5 倍。降到 600 后扛倍翻倍
- **下限 1.5 万→2.5 万**：P25 余额 ~2.2 万，筛掉约 15%，换来扛下限从 5.8→20.1
- **上限 12 万→20 万**：配合底分调整，覆盖 96×
- **P80 扛从 23.2→52.0**：八成玩家在 48× 局不受截断
- 费率 5.1% 偏低（玩家倍数 29.7× 拉高 Vavg），后续可考虑微调服务费
- **P50 扛 23.7× 仍不到 30× 理想值**：受限于玩家群体余额。进一步提升需降底分到 450，但会让 #3-#4 层级过近
