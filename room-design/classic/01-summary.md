> **v3.0 · 2026-07-23**。基于 [00-framework.md](00-framework.md) 方法论重做，取代 v2.x 方案。核心变化：引入**低保兜底 4k**、**练习引导房**，重做底分 / 服务费 / 下限链，并压制高端费率。

**两个关键设定**：

- **练习房 = 新玩家引导流，非余额房**。仅服务新注册玩家前 5 局：配牌 + 机器人陪打 + 包赢，打完送新手房。体量极小（约全量 0.5%、日均 ~1k 新玩家），不计入余额漏斗。
- **低保兜底 4k**。余额 <4k 的回流玩家被顶到 4k → 进新手房，新手成为实际地板。这样新手下限 4k 不会把低余额老玩家挡在门外（线上这类玩家占 ~46%，95% 是回流、非新玩家）。
  - 代价：被顶到 4k 的玩家地主扛 ≈ (4000−120)/(2×150) = **12.9×**，遇到 M12+（地主 mag 24+）会破产截断、靠低保回血。入场级可接受；若要缓冲可把低保发到 ~5k。

## 二、设计方法

1. **下限链干净递进**：4k → 8k → 1.8w → 4w → 9w → 30w，互斥不重叠（相邻房下限即分界，上限仅作天花板、不参与互斥分桶）。
2. **费率公式**：`费率 = 服务费 / (底分 × 农民≤48 倍数 × 三斗系数)`，三斗系数 1.0~1.33（1.33 = 玩家 1/3 当地主赔付 2M、2/3 当农民赔付 M 的期望 4/3·M）。目标 **6-12%**，等级越高费率越高。
3. **倍数基准取农民 ≤48 部分贡献均值**：覆盖 ~87% 对局、跨房间稳定（11.5~12.7），是落在 6-12% 目标的甜点基准。用 ≤24 会偏高（12-16%）、用全部均值会偏低（4-6%，被尾部带飞）。
4. **费底比梯度**：0.60 → 0.80 → 0.94 → 1.00 → 1.20 → 1.20 → 1.20。低房低价引流（练习/新手），高端统一 1.20。

## 六、关键改善点

1. **拆分线上底250 大宽房**。线上底250 区间 [2.5k,2w]（8 倍宽）独扛 63.8%；新方案拆成 新手+初级+中级 三档，粒度更细、升级有感。
2. **压制高端费率**。线上底2500 / 底4000 费率 **16% / 18%**（三斗1.0），远超 12% 天花板——费底比过高（1.6/1.8）叠加大户保守（≤48 仅 ~10）。新方案高端费底比统一 1.20，费率回到 **9.7~12.3%**。
3. **下限链去重叠**。线上相邻房上限拉得过开（底250 上限 2w、底500 上限 5w…）大量重叠；新方案下限链干净递进、互斥不重叠。
4. **练习引导房显式化**。线上底30 已是引导房但混在同一下限段；新方案把练习房定位明确（新玩家前 5 局、配牌包赢），与入门房（新手）彻底分开。

## 七、数据来源与口径

- 表：`tcy_temp.dws_ddz_daily_game`，过滤 `game_id=53 AND play_mode=1 AND robot!=1`。
- 窗口：2026-06-22 ~ 2026-07-21（30 个完整天）。
- **互斥下限链**：每局归入携银（`start_money`）能进的最高下限房，占比合计 100%。
- **新方案分布**：模拟低保兜底 4k（原 <4k 全顶到 4k 进新手），故新手 = 所有 <8k。
- **线上分布**：按对局实际所在 `room_base` 统计（非模拟）。
- **农民 ≤48 倍数**：`Σ(magnification, mag<=48) / 总局数`（部分贡献均值），仅 role=2。
- **三斗系数**：1.0（纯农民视角，保守）/ 1.33（含地主 1/3 概率的期望赔付）。
