# 房间 #5 — 高级场

## 定位

高净值玩家的主战场。底分 2,500，当前问题不是扛倍数偏低，而是**上限锁死 30 万**——地主最多扛 59×，96× 局结构上不可能结算。本次仅放开上限，其余参数不动。

对应线上房间：**10336**（底分 2,500）。

## 参数

| 项目 | 当前值 | **调整值** |
| ---- | ---- | ---- |
| 底分（room_base） | 2,500 | 不变 |
| 入场下限（room_currency_lower） | 5 万 | 不变 |
| 入场上限（room_currency_upper） | 30 万 | **80 万** |
| 服务费（room_fee） | 4,000 | 不变 |
| 区间 | — | **[—, 96×]** |

## 区间覆盖

```
扛下限 9.2×   → 未达 12×（后续优化）
P50 扛 17.2×  → 覆盖 12×（P50 理论）
P80 扛 27.9×  → 覆盖 24×（P75 理论）
扛上限 155.2× → 覆盖 96×（P95 理论）← 解锁
```

## 设计推导

- **仅放开上限 30 万→80 万**：当前最大问题。30 万上限锁死地主扛 59×，96× 局（占 5.9%）需地主余额 ≥ 24.4 万 → 超上限，结构上不可能。放至 80 万后，有钱就能足额结算
- **零伤害改动**：现有玩家不受任何影响（下限、底分、费率全不变），只是允许玩家带更多钱进场——纯增益
- 扛下限 9.2× 偏低，但 #5 玩家 P50 余额 8.9 万，实际扛 17.2× 够用
- 建议作为**首个执行**的改动，建立信心

## 改动说明

| 参数 | 改动 | 幅度 | 风险 |
| ---- | ---- | :---: | :--- |
| 上限 | 30 万 → 80 万 | +167% | **零**（纯放开，不影响现有玩家） |
