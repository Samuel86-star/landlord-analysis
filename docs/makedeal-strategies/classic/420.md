# 房间 420 · old2 → new2（改造中）

> 420 原和其他经典房一样跑 `old2`（多炸）。现按本仓库 TOP 推荐（`classic-makedeal-config-topn.md` Type1 #1）切换到 `new2 = with-pair [4,6,5,2,3] b14 sel17`。是继 742 之后第二个吃 Type1 降炸方案的经典房，也是**第一个用 `with-pair`（收对）均衡档**的房（742 用的是 `no-pair` 少炸档）。
