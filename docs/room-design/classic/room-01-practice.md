# 房间 #1 — 练习房

## 定位

**新玩家引导流，非余额房**。仅服务新注册玩家前 5 局：配牌 + 机器人陪打 + 包赢，把余额抬到 ≥4k 后送新手房。下限/上限不参与余额漏斗。

---

## 配置

| 参数 | 值 | 说明 |
| :--- | ---: | :--- |
| 底分 | 50 | 引导局分量 |
| 服务费 | 30 | 费底比 0.60，低费 |
| 下限 | 1,500 | （引导流，不按余额筛人） |
| 上限 | 5,000 | （同上） |

---

## 人群

引导流体量极小：约全量 **0.5%**、日均 ~1,000 新玩家。不计入余额漏斗（见 [01-summary.md](01-summary.md) 第三节）。

---

## 设计要点

- **配牌包赢**：前 5 局让新玩家赢钱，余额自然升到新手下限 4k 以上，平滑衔接到新手房。
- **费率参考性质**：按 <8k 农民 ≤48≈11.7 估算费率 ~5.1%（三斗1.0），但引导局是配牌、非自然对局，费率/扛倍数均不具经营意义。
- **扛倍数无意义**：包赢局不发生真实破产截断。
