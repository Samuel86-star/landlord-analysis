# 房间 #4 — 中级房

## 定位

中坚房。承接初级上进玩家（1.8w+），下限链第三档。

---

## 配置

| 参数 | 值 | 说明 |
| :--- | ---: | :--- |
| 底分 | 750 | 中坚分量 |
| 服务费 | 750 | 费底比 1.00（费=底） |
| 下限 | 18,000 | 衔接初级（上限 24k） |
| 上限 | 60,000 | 衔接高级（下限 4w） |

> 上限 6w 对互斥分布无影响——中级/高级分界看高级下限 4w（互斥下限链），上限仅作天花板。

---

## 费率

农民 ≤48 基准：**8.49%**（三斗1.0）/ 6.38%（三斗1.33）。

---

## 设计要点

- **扛下限 11.5×**（七房最低）：下限 1.8w 卡得最紧，进场地主 M12+ 即截断。若要缓冲可下调下限或上调底分，但会改费率。
- 费底比 1.00 是七档费率的分水岭（低房 <1.0 引流、高房 1.2）。
