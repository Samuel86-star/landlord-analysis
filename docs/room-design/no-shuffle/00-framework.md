# 不洗牌斗地主房间设计 — 框架（草案）

> **v0.1 · 2026-07-27**。本文件是不洗牌房间设计的起点骨架，**尚未含任何底分/费率数值**——数值待数据抽取后由本周设计工作填入。方法论数学框架直接复用经典玩法：[`../classic/00-framework.md`](../classic/00-framework.md)。

---

## 一、玩法定位

- 不洗牌 = `game_id = 53 AND play_mode = 2`（与经典 `play_mode = 1` 同游戏、不同玩法）。
- 三玩法（经典 / 明牌 / 不洗牌）中**留存最高**，首日约占 11% 流量（参考 [`competitor/huanxi`](../competitor/huanxi-ddz-room-config.md) 竞品对标记录）。
- 设计目标：为不洗牌单独搭一套底分 / 费率 / 封顶配置，**不与经典房混用**（倍数尾部量级不同）。

---

## 二、与经典的机制差异（影响房间设计的关键）

1. **极端高倍**：不洗牌 magnification 可达极高值（如 98304 量级），破产截断比经典更激进 → **封顶与扛倍数区间权重远大于经典**，是本玩法的核心设计变量。口径见 [`game-combat §六`](../../knowledge/game-combat-analysis.md)（98304 等极端高倍为机制产物、非脏数据）。
2. **倍数分布须重抽**：经典实测倍数分布（[`classic/00-framework`](../classic/00-framework.md) 各等级房间倍数分布）**不适用**于不洗牌——尾部更厚。底分 / 封顶设计必须基于不洗牌自身分布。

---

## 三、可复用方法论（来自经典框架）

下列数学框架玩法无关，直接沿用 [`../classic/00-framework.md`](../classic/00-framework.md)：

- 理论倍数 `magnification` vs 实际倍数 `real_magnification`；破产截断判定。
- **兑现率** = AVG(real_mag) / AVG(mag)，目标 ≥ 0.80。
- **扛倍数**：地主扛 = (携银 − 服务费) / (2 × 底分)，农民扛 = 2 × 地主扛。
- **房间区间** = [扛下限, 扛上限]。
- **服务费率** = 服务费 / (底分 × 农民倍数 × 三斗系数)，目标 6–12%。
- 设计原则：升级有感、安全垫(≥1.2×)、上限不锁死、费率递增、最小改动。

> 不洗牌独有的参数（封顶策略、扛倍数安全垫倍率）待第二章差异点驱动后在本文件补充。
