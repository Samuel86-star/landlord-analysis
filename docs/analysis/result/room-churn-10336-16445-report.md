## 二、队列去向：核心答案

口径：基线（08-08~08-18）在该房有 ≥1 局的真人 → 观察期（08-20~08-24）行为分类。一人若两房都玩过则分别计入两队列。

| 观察期去向 | 10336 队列（1695 人） | 16445 队列（586 人） |
| ---------- | --------------------- | -------------------- |
| 仍在原房间 | 149（8.8%） | 87（14.8%） |
| 只去其他经典房间 | **1211（71.4%）** | **369（63.0%）** |
| 只玩其他玩法 | 2（0.1%） | 4（0.7%） |

**"彻底未登录"是否异常？** 同期（同窗口、同口径）其他经典房间队列的彻底未登录率：420 为 29.4%、4484 为 34.6%、6314 为 21.8%、11168 为 19.5%、12074 为 35.5%。两房间队列的 17.9%/19.6% **不高于任何对照**，且大盘平稳 → **没有超额的游戏级流失，基本可以排除"人没了"**。

- **越高等级跌得越狠**，新手房是唯一大增房——整个经典 ladder 在 08-19 发生了一次自上而下的下移。
