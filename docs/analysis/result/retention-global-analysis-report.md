# 斗地主新增留存分析报告（全局层）

> **分析目标**：基于全局层数据（2026-02-10 至 2026-05-10），分析斗地主新用户留存的核心影响因子，识别高危流失画像，输出产品干预建议。
>
> **数据范围**：全体新增注册用户（以 APP 端设备为主）。

---

## 一、 用户属性：大盘留存基线

### 1. 渠道差异显著，需警惕低质渠道

根据渠道日度留存数据（二/1.md）：

- **高留存梯队**：`官方(非CPS)`（次留约 20%-60%+ 波动，中枢较高）、`荣耀`（次留多在 20%-40% 间）。
- **中留存梯队**：`华为`、`vivo`、`OPPO` 等主流硬核联盟渠道，次留稳定在 15%-25% 之间。其中华为表现最好，稳定在 20%+。
- **低留存梯队**：`咪咕` 渠道次留极低（大多数日期 <10%，多日为个位数或 0），疑似存在大量刷量或非目标用户，建议市场部门排查该渠道质量。`iOS` 渠道表现出极大的不稳定性，前期（2-3月）次留多在 15-25% 间波动，近期（4月底至5月）出现多日个位数甚至为 0 的情况，且注册量偏低。

### 2. 客户端版本与设备差异

- **设备端**：Android 注册量（10.2万）远超 iOS（7.1千）。两者留存基线接近（Android 次留 22.75%，iOS 次留 23.84%）。
- **客户端版本**：`Cocos-Creator` 引擎版本（注册量 9.3千）的留存（次留 28.33%，七留 14.89%）显著优于 `Cocos-Lua` 版本（注册量 10万，次留 22.31%，七留 10.64%）。这强烈暗示 **Cocos-Creator 版本可能在性能、稳定性或体验上存在优势**，建议技术团队加快全量迁移至 Creator 版本的评估。

---

## 二、 投入度：对局数量与留存的“倒U型”关系

- **零局用户流失**：未参与对局的用户占约 14%（1.5万），其次留为 17.47%，低于正常体验游戏的用户。
- **留存最优区间**：随着首日对局数增加，留存率先升后降。
  - 1局（10.18%） → 2-5局（16.40%） → **6-10局（22.29%）** → **10局+（34.87%）**。
  - 数据显示对局数越多，次留越高。但需注意，1局用户的留存（10.18%）极其糟糕，甚至低于无对局用户（17.47%），这说明 **首次对局体验极差（如卡顿、匹配机制不合理、立刻输光）导致了严重的“被劝退”流失**，这是首要解决的痛点。

---

## 三、 胜负情绪线：胜率与连败是留存的生命线

### 1. 胜率断崖式下跌点

- 胜率 `<30%` 的用户次留仅 **16.09%**。
- 胜率维持在 `30%-70%` 之间的用户，留存最佳（次留 26%-29%）。
- **过度连胜并非最优**：胜率 `>=70%` 的用户留存反而下降到 **18.57%**，且其平均对局数仅为 4.7 局（远低于正常用户的 14 局）。这可能说明过度连胜会让用户觉得“无聊/缺乏挑战”而提早结束游戏，或者这部分是遇到极端顺风局后“见好就收”的轻度用户。

### 2. 连败是关键预警指标

与常识相反，数据（三/3.md）呈现出 **连败次数越多，留存越高** 的反常识现象：无连败（5.9%） -> 1-2连败（10.69%） -> 3-5连败（28.96%） -> 5+连败（35.64%）。

**【深刻反思】**：这在数据分析中称为 **幸存者偏差（或因果倒置）**。这不意味着“连败让人更想玩”，而是“只有那些深度沉迷、对局数极大（比如玩了 100 局）的重度用户，才有可能打出 5 连败的记录”。对局数少、稍有挫败就流失的用户，根本没机会积累 5 连败。

- 因此，直接看连败与留存的相关性会被“首日总对局数”这一隐藏变量污染。建议在后续分析中，控制首日对局数（如：限定看都玩了 10 局的用户），再对比连败带来的流失。

### 3. 首局胜负效应

- **首局胜**：次留 24.73%。
- **首局负**：次留 20.94%。

首局胜利能带来约 4% 的留存优势。

## 四、 经济压力与刺激体验：倍数、底注与角色

### 1. 银子净变化与破产（核心痛点）

- **赢钱留存更好**：大赚/巨赚（1万银子以上）的用户，留存高达 30%-37%。
- **大亏直接流失**：净亏损在 1万-5万 的用户，留存跌至 26.97%；而“巨亏 <-5万”的极小部分用户（可能是高 V 或大 R 被快杀）留存却高达 50%（样本量极小，仅 162 人，可能多为充值后继续战斗的大 R）。
- **破产等于流失（警报！）**：未破产用户次留 18.28%，而疑似破产（银子≤1000）的庞大群体（6.6 万人，占总数 60%）留存虽有 26%（同样受沉迷用户对局多容易破产的幸存者偏差影响）。真正的痛点应结合下文的高危组合来看。

### 2. 高倍局：双刃剑

- 未经历高倍局留存：16.87%
- 经历高倍局且有输有赢：29.54%（最健康的游戏体验）
- **倍数最适区间**：平均倍数在 12-24倍 之间留存最高（25.91%），这说明用户需要刺激，但不宜过大。

### 3. 角色扮演体验

- **偏好农民（占比<30%做地主）** 留存最高（34.99%），这群人可能打法保守，依赖队友。
- **偏好地主（占比≥60%）** 的激进型玩家，留存反而较低（20.40%），原因是地主输赢方差太大，容易一把破产。
- **纯农民**（一局地主都没抢过）留存极低（12.43%），这部分很可能是规则没搞懂的纯新手，或极度厌恶风险的低质量用户。

### 4. 房间底注体验

- 玩家主要集中在 `中底注(201-1000)` 房间（8.2 万人，次留 22.98%）。
- 在 `低底注(51-200)` 房间的用户（1.1 万人）留存更好，达到 28.02%。
- 建议：强制新手在前 N 局只能留在低底注房间，避免过早进入中底注房间被高倍打穿。

## 五、 高危组合与干预建议

数据（五/1.md）揭示了一个高危事实：

- **大亏用户（未连败3+）** 的次留暴跌至仅 **3.56%**！这才是真正的流失重灾区。这些用户可能遭遇了被“一把清空”（如遇到炸弹局当地主输光），瞬间挫败感极强。
- 由于上面提到的幸存者偏差，组合了“连败3+”的用户反而留存高达 36%（因为他们玩了足够多局）。

### 核心干预建议

1. **P0级：拯救“一把没”的大亏用户**
   - **现象**：没有经历多局连败，但突然出现银子大亏的用户，留存不到 4%。
   - **对策**：触发大额输牌（例如单局输掉携带银子的 80%）时，强制弹出低保救济金领取页面，或触发系统“怜悯机制”（下一局强力配好牌）。
2. **P0级：修复首局劝退体验（1局用户流失）**
   - **现象**：玩 1 局就走的用户留存（10%）比不玩游戏的人还低。
   - **对策**：加强首局新手保护（查验之前的 SQL 是否证实首局匹配了 2 个机器人）；如果是机器人局仍输了，说明配牌策略或 AI 逻辑有问题，需给新手配必胜的起手牌。
3. **P1级：新引擎迁移**
   - Cocos-Creator 版本留存数据在各方面均好于 Lua 版本，建议技术侧提速迁移流程，淘汰 Lua 客户端。
4. **P1级：渠道优化**
   - 咪咕渠道的数据表现极度异常，建议立即停止或严审该渠道买量。iOS 渠道近期断崖式下跌，需排查是否有近期包体提审、版本更新导致的严重闪退/黑屏 BUG。
