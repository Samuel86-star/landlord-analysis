# 发牌策略调优阶段性成果汇报（Delta-Power 引导度引入）

> 日期：2026-08-07 ｜ 范围：742/420 经典房 Type1 发牌 ｜ 状态：**模拟 + 线上 A/B 闭环验证完成**
> 真值来源：`algorithm/native/extracted/`（harness 1:1 + 搜索式最优拆牌，决赛 N=20000）

## 一、核心结论（TL;DR）

1. **问题定位**：Type1 发牌虽手数/单牌优异，但出现"过均衡"——首叫诱导度 1.21~1.25、抗衡度 1.42~1.49，三家过于均顺、缺明确叫牌引导位，存在**叫牌断层 + 底牌随机干扰过大**风险。
2. **根因在 Fitness，不在发牌算法**：原 `S_susp` 的首叫 band `[1.05, 基线]` 对 1.21 与 1.28 一视同仁、抗衡度无上限 → sweep 被**系统性推向"过均衡"**。发牌管线 1:1 线上、无 bug。
3. **"叫牌断层"被量化**：新增指标 **引导度 Delta-Power**。实测 **现行 new(742) Δ=0.198 已落入过均衡区（<0.20）**；new2(420) Δ=0.208 刚进健康带；纯随机 0.259 为自然上界参照。
4. **L1 修正（零发牌改动）已落地验证**：Fitness 改三项双限带，TOP1 由过均衡配置转为结构更健康的 new2。

## 二、调优动作（L1：Fitness + 引导度指标）

| 项 | 调整前 | 调整后 |
|---|---|---|
| 引导度 Δ | 无 | (P_max−P_mid)/P_max，P=sigmoid(牌力/40)+0.10·持有炸 |
| S_susp 分解 | 0.5·S_hs + 0.5·S_res | **0.34·S_hs + 0.33·S_res + 0.33·S_delta** |
| 首叫带 | [1.05, 1.328]（过宽，1.21/1.28 同分） | [1.26, 1.40] |
| 抗衡带 | ≥1.299（**无上限**，越均衡越高分） | [1.30, 1.45]（加上限） |
| Delta 带 | — | [0.20, 0.26]（<0.20 过均衡，>0.26 碾压） |

> **标定严谨性**：delta_ratio 全分布实测 0.148~0.262。初设 band 曾方向反转（会奖励过均衡、惩罚纯随机），按实测分布修正为 [0.20, 0.26]——**"先校准再定带"避免了一次静默的错误排名**。

## 五、线上 A/B 实测数据验证（2026-08-05 crossover，全真人桌）

### 5.1 实测对比（全真人桌）

> old2 基线日 **2026-07-30**（实测切换点：742 于 **07-31** 切 Type1、420 于 **08-04** 切 Type1；07-30 为两房同 old2 的最后单日）；new/new2 为 2026-08-05 crossover。N：new≈38.5k / new2≈31.5k / old2≈48k 局。

| 指标 | old2 (Type0, 07-30) | new (742) | new2 (420) |
|---|---|---|---|
| 无人抢地主率（grab=3） | **81.21%**（最活跃） | 86.37% | 87.99%（最断层） |
| 流局率（无地主局） | 0% | 0% | 0%（默认叫地下恒 0） |
| 地主胜率 | **51.61%**（最均衡） | 53.66% | 61.31%（地主主导） |
| 地主牌力方差 sd | **34.74**（最不 coin-flippy） | 35.0 | 38.37（最 coin-flippy） |
| 地主 avg 牌力(final) | 48.26 | 46.68 | 54.45 |
| avg 实际倍数 | **14.73**（最高，炸多） | 10.41 | 10.33 |
| 持有炸/人（sim） | 0.419 | 0.138 | 0.140 |

> **关键**：无人抢率 old2(81%) < new(86%) < new2(88%)，与持有炸正相关——Type1 的"高无人抢"是"少炸"的副产品。但 **new 以 1/3 的炸弹（0.138 vs old2 0.419）复刻了 old2 的胜负均衡**（胜率 53.7%/方差 35.0 ≈ old2 51.6%/34.7），且无 old2 的 14.7 倍高刺激——这是 Type1 控制发牌相对 Type0 的核心价值。

### 5.2 关键算法洞察：Delta-Power 的应用边界

A/B 揭示两个**独立**的轴，原假设曾将其混淆：

- **叫牌意愿轴**（玩家能看到的 3×17，由 Δ 衡量）：new≈new2（Δ 0.198 vs 0.208）→ 无人抢率几乎相同（86.4% vs 88.0%）。**Δ 在此轴有效。**
- **胜负稳定性轴**（玩家看不到的底牌，决定 coin-flippy）：new2 的 with-pair 让底牌大量补成炸弹（sim 地主20炸 new2=0.633 vs new=0.343）→ 地主更强、方差更大 → 胜率 61% / 方差 38。**Δ 对此轴完全失明。**

> ⚠️ **Δ 不能独立用于决策**：单看 Δ，new2(0.208) > new(0.198)，会微弱偏向选 new2——**与线上真实结论相反**。必须与"地主20真实炸弹口径"（或胜率方差）联合约束。

### 5.3 最终业务选型结论

**经典/低等级房选 `new`（no-pair 路线），放弃 `new2`（with-pair 路线）。**

- new 地主胜率 53.7% / 方差 35（更均衡、更少 coin-flippy）；new2 胜率 61.3% / 方差 38（地主主导 + 底牌暴击大起大落）。
- 对比 old2 基线（07-30）：new 以 1/3 的炸弹（0.138 vs 0.419）达成 old2 同等的胜负均衡（方差 35.0 vs 34.7），且避免 old2 的 14.7 倍高刺激——old2 的均衡是炸弹滥发换来的，不可取。
- 与 `docs/knowledge/makedeal-simulation.md` §4 模拟预测（"底牌对 new2 加成巨大 +0.37…new 比 new2 实战干净得多"）**完全互证**——线上数据坐实模拟。
- 完整方法论见 SOP `docs/knowledge/makedeal-evaluation-sop.md`。
