二、设计逻辑

核心公式：地主可扛倍数

地主是支付瓶颈（需同时付 2 个农民），任何对局的理论倍数超过「可扛倍数」即发生破产截断。

地主可扛倍数 = (玩家携银 − 服务费) / (2 × 底分)

设计约束：每间房的下限可扛 ≥ P50 理论倍数（~12×）——按下限进场的玩家，过半对局不受截断。

设计原则

#原则含义
1下限扛 P50任何按下限进场的玩家，≤12× 的对局不截断
2P50 扛 P75房间中位玩家在 75% 的对局中零压降
3上限不锁死天花板足够高，有钱就能足额结算
4费率一致服务费 ≈ 1.5-1.8× 底分，维持当前体系
5逐级拉开底分/下限形成清晰梯度，玩家自然分流
