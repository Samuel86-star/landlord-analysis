二、设计说明

约束条件

#约束量化标准
1扛下限单调递增每升一级，按下限进场的扛倍数必须更高
2P50扛单调递增每升一级，中位玩家的扛倍数必须更高 → 升级有实在好处
3服务费率单调递增更高等级 = 更好服务 = 更高费率，6-12% 区间
4上限分层覆盖48× / 48× / 96× / 192× / 192× / 384× / 无上限
5兑现率 ≥ 0.80P50扛 ≥ 30×

核心公式

地主扛 = (携银 − 服务费) / (2 × 底分)
Vavg = 底分 × 农民平均倍数 × 三斗系数
费率 = 服务费 / Vavg
