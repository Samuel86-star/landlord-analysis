## 指标怎么看（新口径）

| 指标 | 大白话 | 判断标准（低等级经典房） |
|---|---|---|
| **单局炸弹率** | 整桌 3 人有任意炸弹的局占比 | **趋近纯随机 0.461**（"抱随机"是低等级核心理念） |
| 持有炸(人均) | 每家平均持有炸弹(四张/王炸)颗数 | 自然≈0.189；持有口径稳、与线上 `bomb_cnt` 对齐 |
| 0/1/2/3+炸密度 | 桌上炸弹总数 K 的分布 | 0 炸局占比越高越"不假" |
| **人均最优手数** | 最优拆牌(min-combo)下每家几手出完 | **越小越顺**；自然≈7.34 |
| 人均散牌 | 最优拆牌里孤立单牌数 | 越少越成型 |
| 首叫诱导度 P_max/P_avg | 最强家/均家 牌力比 | ≈1.2~1.3，有强叫意愿又不碾压 |
| 抗衡度 (P_mid+P_min)/P_max | 两弱家联合/最强家 | 越高农民越能抗、悬念足（自然≈1.30） |

> P = sigmoid(牌力/40)（归一化非负强度）。**炸弹看"持有"**：最优拆牌(min-combo)会把孤立四张吸成"四带二"，故"拆牌炸弹"偏低，炸弹维度必须以持有为准。
> **适应度**（基线=纯随机）：`.28·S_bomb(单局炸率抱随机)+.18·S_hand+.12·S_single+.20·S_susp(首叫+抗衡)+.10·S_div+.12·S_hit`。

## 牌型码 & 关键参数

**`CouPaiStrategy` = 拼牌时优先凑什么牌型的顺序**，码：`2`对 `3`三 `4`顺 `5`连对 `6`飞机 `13`炸。
- **`no-pair`/`no-bomb`**（不带 2、不带 13）：不收对、不凑炸 → 少炸偏自然，但手数偏高。代表 `[4,5,3,6]`（=线上 `new`）/ `[4,6,5,3,2]`。
- **`with-pair`**（带 2）：收对 → 牌成型好打、同点聚集 → 炸弹略多。代表 `[4,6,5,2,3]`（=线上 `new2`）。
- **`bomb-last`**（末位带 13）：把炸码放最后，**让炸弹分布更贴自然**（低等级 TOP 家族）。代表 `[4,6,5,3,2,13]`。
- `BeginMakeNum`(b)=前 N 张纯随机；`BeginSelectBanker`(s)=干预停止位；`TargetValue=999`=恒拼牌。

## 怎么选（一句话）

- **低等级经典房（742/420）→ Type1**：已上线（742 `new`）/改造中（420 `new2`）。要更贴自然就上 **Type1 TOP1 `bomb-last [4,6,5,3,2,13] b11 s15`**（单局炸率 0.454≈自然、手 5.51、抗衡 1.47）。
- **更高等级房 → Type0**：要更多炸弹/倍数/爽感时，Type0 的多炸从缺点变卖点；TOP1 `thr3 bmn14`（单局炸率 0.607）。
- **要最少炸** → Type1 `no-pair`/`with-pair b13+`（持有炸可压到 ~0.14），但按"抱随机"理念会扣分（过低也扣）。
