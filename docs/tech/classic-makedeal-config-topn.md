# 经典玩法做牌配置组合 TOP N 速查

> 一页速查：哪些发牌配置能同时照顾好 **炸弹数、出牌手数、庄闲公平** 几条。
> 数据来自模拟器（`old2_type0_sim.py` / `old2_type1_sim.py`），N=4000 局×3 家、同一副牌、手数用 t0拆口径。
> 配套：完整落地方案见 [`classic-makedeal-debomb-plan.md`](classic-makedeal-debomb-plan.md)。

> ⚠️ **重要更正（2026-08-05，harness 真值）**：下文所有数字来自**贪心拆牌**的 Python 模拟（`old2_type*_sim.py`），
> 已被 1:1 剥离线上 C++ 的独立模拟器 [`algorithm/native/extracted/harness.cpp`](../../algorithm/native/extracted/README.md) **部分推翻**：
> - **742 / 420 持有炸弹实际 ≈ 0.137 / 0.138（几乎相同）**，不是下表的 0.16 / 0.20；
> - **"对(2)顶炸悬崖"（with-pair ≫ no-pair）是贪心拆牌的伪影，线上不存在**；
> - 下表 TOP N 排名**仅供方向性参考**（跨配置相对快慢仍可信），**精确概率以 harness 为准**。
>   如需据此做上线取舍，请先用 `harness --room <id> --reals 3 -n 100000` 复核对应配置。

## 五个指标怎么看（通俗）

| 指标 | 大白话 | 判断标准 |
|---|---|---|
| **炸弹数** | 一手牌里平均几个炸弹（4 张同点，或双王） | 越接近自然 **0.19** 越真实；经典房现状 **0.43**（太多，玩家嫌"假"） |
| **手数** | 这手牌大概几手能打完 | **越少越好打**（牌顺）；纯随机约 7.5 手 |
| **庄闲炸差** | 庄家(真人)炸弹数 − 闲家(机器人)炸弹数 | **越接近 0 越公平**，防真人被机器人炸弹欺负 |
| 单牌数 ↓（参考） | 拆完所有牌型后，剩几张单牌 | **越少越好**，牌越成型不散 |
| 庄闲大牌差（参考） | 庄的大牌(2/王) − 闲的大牌(2/王) | **越接近 0 越公平**；+ 表示庄被多塞大牌（优待真人） |

> **为什么大牌数要看"庄闲差"**：每个玩家自然人均大牌 ≈ 1.89 张（2+王一共 6 张分三家），所有配置都贴这个数，所以"人均大牌"不分辨。但**庄家和闲家的大牌分配**差别很大——见下文两表，这是公平性的第二条线。

**TOP N 怎么排**：综合评分 = `0.5×距0.19 + 0.3×手数 + 0.2×|庄闲炸差|`（各指标同类内归一化，越小越好）。**降炸是核心目标，所以炸弹权重最高**；手数次之；庄闲炸差再次。`单牌数`、`庄闲大牌差` 是**参考列**（不进评分）——前者与手数相关会重复加权，后者是 Type0 的有意设计（优待真人），算缺点会不公。

## 牌型码 & 关键参数（通俗）

**`CouPaiStrategy` = 系统干预时优先凑什么牌型的顺序**，码：`2`对子 `3`三张 `4`顺子 `5`连对 `6`飞机 `13`炸弹。

- **`with-pair`（收对）**：策略带 `2`，系统把单牌凑成对子 → 牌成型、好打，但同点聚集 → 炸弹略多。代表 `[4,6,5,2,3]`。
- **`no-pair`（不收对）**：策略不带 `2`，不主动凑对 → 牌散、少炸偏自然，但手数偏高。代表 `[4,5,3,6]`（=线上 `new`）。
- 两者**就差一个 `2`**。

**两个数值参数**（Type1 配置用）：
- **`BeginMakeNum`（bN）**：前 N 张纯随机发，第 N+1 张起系统干预。N 越大越自然。
- **`BeginSelectBanker`（selN）**：干预到第几张停。`sel17`=把后面空位都干预填满（线上 robot/newuser 即此值）；`sel15`=只干预一段、剩下随机填。

**Type0 的"control-flow（控制流）"**：改写死在 C++ 的做牌菜单顺序，把"凑炸弹"那步挪到最后；`bmnN` = `BeginMakeNum`。

## 怎么选（一句话）

- **能改代码 + 要最好打** → **Type0 `control-flow bmn10`**（0.20 炸 / 5.8 手，全局最优；但庄家被多塞大牌 +0.23，略有优待）。
- **不能改代码 + 要公平** → **Type1 `with-pair [4,6,5,2,3] b14 sel17`**（0.21 炸 / 6.2 手，庄闲炸差≈0、庄闲大牌差≈0，最公平）。
- **要最少炸** → Type0 `control-flow-nobomb bmn10`（0.14 炸）或 Type1 `no-pair b10 sel15`（0.15 炸），代价是手数高 / 无爽点。
- 两条路现状都该改：Type0 baseline 0.43 炸、Type1 default **0.54** 炸。

> 铁律：**"0.19 炸 + 6 手以下"只有 Type0 控制流给得出**；Type1 要 0.19 炸手数就得上 7。
> Type0 的"好"部分靠给真人多大牌（控制力）+ 给闲家略多炸来平衡；Type1 不偏袒、更自然，但手数高一档。

## 附：评分与口径

- **评分** = `0.5×|炸弹−0.19| + 0.3×手数 + 0.2×|庄闲炸差|`，三指标各自在**同类（Type1 / Type0）候选池内**归一化到 [0,1]，加权求和，**越小越好**。`单牌数`、`庄闲大牌差` 只展示、不进评分。
- 炸弹用"距 0.19 的距离"而非"越低越好"：目标是**贴近自然 0.19**，过低（无爽点）也扣分。
- `现状(default/baseline)` 作为参照移出排名池，避免拉飞归一化。
- 手数是贪心拆牌的估计值（t0拆口径），绝对值供参考、**跨配置排序可靠**；N=4000，中段排名有 ±0.01 评分的统计噪声，头部稳定。最终标定需对线上 `bomb_cnt` / `card_power` 日志（742 房已有实测，见 memory）。
