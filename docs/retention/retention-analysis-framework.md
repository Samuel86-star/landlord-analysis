## 二、留存相关指标（影响力金字塔）

```mermaid
graph TD
    subgraph 高相关性 [🔴 高相关性 - 直接影响留存]
        A1[首日对局数]
        A2[首日胜率]
        A3[连败长度]
        A4[银子净变化]
        A5[是否破产]
        A6[高倍局输赢]
    end
    
    subgraph 中等相关性 [🟡 中等相关性 - 需分场景分析]
        B1[首日平均倍数]
        B2[首局胜负]
        B3[逃跑次数]
        B4[房间匹配度]
        B5[玩法选择]
    end
    
    subgraph 背景指标 [⚪ 背景指标 - 区分用户类型]
        C1[渠道分类]
        C2[客户端版本]
        C3[注册时段]
        C4[炸弹数/春天]
    end
    
    高相关性 --> 中等相关性
    中等相关性 --> 背景指标
```

### 2.1 高相关性指标（直接影响留存）

| 指标 | 分组方式 | 留存规律（已验证） |
| ---- | ---- | ---- |
| **首日对局数** | 0局/1局/2-5局/6-10局/10+局 | 存在最优区间（6-10局），过少未形成习惯，过多可能疲劳 |
| **首日胜率** | <30%/30-50%/50-70%/70%+ | 胜率<30%流失风险极高，胜率与留存正相关 |
| **连败长度** | 0-1/2-3/4-5/5+ | 连败≥3局流失概率急剧上升，关键流失预警信号 |
| **银子净变化** | 巨亏(<-5万)/大亏(-5万~-1万)/小亏(-1万~0)/小赚(0~1万)/大赚(1万~5万)/巨赚(>5万) | 净亏损用户留存显著低于盈利用户 |
| **是否破产** | 银子谷值≤最低房间门槛 | 破产后直接退出比例高，经济系统兜底的核心指标 |
| **高倍局输赢** | 仅赢高倍/仅输高倍/有赢有输 | 输高倍（>24x）是流失高危信号，赢高倍留存提升 |

### 2.2 中等相关性指标（需分场景分析）

| 指标 | 分组方式 | 留存规律 |
| ---- | ---- | ---- |
| **首日平均倍数** | ≤6/6-12/12-24/24+ | 倒U型关系，12-24x留存最优（非越高越好） |
| **首局胜负** | 胜/负 | 首局胜率预期偏高（新手配牌），首局负留存显著低 |
| **逃跑次数** | 0/1/2/3+ | 逃跑反映挫败感，逃跑率>15%留存极低 |
| **房间匹配度** | 携银/房间门槛比值 | 比值<3（携银刚够门槛）风险高，易被快速淘汰 |
| **玩法选择** | 单玩法/多玩法 | 多玩法探索用户留存更高（兴趣广） |

### 2.3 弱相关性/背景指标（区分用户类型）

| 指标 | 作用 |
| ---- | ---- |
| **渠道分类** | 区分渠道质量，非产品问题 |
| **客户端版本** | 识别稳定性差异（多次登录=崩溃信号） |
| **注册时段** | 区分用户画像（夜间玩家/白天玩家），时段本身无因果 |
| **炸弹数、春天发生率** | 游戏体验细节，需分玩法看（癞子天然高倍） |

## 三、流失高危信号组合

```mermaid
flowchart TD
    Start[用户行为检测]
    
    Start --> Check1{连败≥3局?}
    Check1 -- 是 --> Check2{银子亏损?}
    Check2 -- 是 --> Check3{高倍局输?}
    Check3 -- 是 --> P0A[🔴 P0: 极低留存<br/>连败×亏损×高倍输]
    
    Check1 -- 否 --> Check4{首局结果?}
    Check4 -- 负 --> Check5{角色=地主?}
    Check5 -- 是 --> Check6{高倍局?}
    Check6 -- 是 --> P0B[🔴 P0: 低留存<br/>首局负×地主×高倍]
    
    Check4 -- 胜 --> Check7{对局数?}
    Check7 -- 0/1局 --> Check8{登录次数≥3?}
    Check8 -- 是 --> P0C[🔴 P0: 崩溃信号<br/>低对局×多次登录]
    
    Check7 -- 多局 --> Check9{破产状态?}
    Check9 -- 是 --> P1A[🟡 P1: 破产后退出]
    
    Check9 -- 否 --> Check10{胜率<30%?}
    Check10 -- 是 --> Check11{对局数≤2?}
    Check11 -- 是 --> P1B[🟡 P1: 低胜率×低投入]
    
    P0A & P0B & P0C --> Action[立即干预]
    P1A & P1B --> Monitor[重点监控]
```

| 组合特征 | 留存预期 | 优先级 |
| ---- | ---- | ---- |
| **连败≥3 + 银子亏损 + 高倍局输** | 极低（<10%） | P0 |
| **首局负 + 地主角色 + 高倍局** | 低（<15%） | P0 |
| **0局/1局 + 多次登录（≥3）** | 低（崩溃/掉线） | P0 |
| **破产 + 不再对局** | 极低 | P1 |
| **胜率<30% + 对局数少（≤2）** | 低 | P1 |

## 四、分析路径建议

```mermaid
flowchart LR
    Step1[Step 1: 留存概览<br/>建立基线] --> Step2[Step 2: 高相关性指标<br/>确认规律]
    Step2 --> Step3[Step 3: 多维交叉<br/>定位高危组合]
    Step3 --> Step4[Step 4: 专项下钻<br/>找根因]
    Step4 --> Step5[Step 5: 行动建议<br/>优先级排序]
    
    Step1 --> |渠道/设备/客户端| S1[基线留存率]
    Step2 --> |胜率/连败/破产| S2[规律验证]
    Step3 --> |连败×破产×高倍| S3[高危画像]
    Step4 --> |对手构成/稳定性| S4[根因定位]
    Step5 --> |P0保护/P1引导| S5[干预方案]
```

```text
Step 1: 留存概览 → 建立基线（渠道/设备/客户端分组留存）
  ↓
Step 2: 高相关性指标分组 → 确认规律（胜率/连败/破产/高倍局）
  ↓
Step 3: 多维交叉 → 定位高危组合（连败×破产×高倍输）
  ↓
Step 4: 专项下钻 → 找根因（1局用户对手构成/客户端稳定性）
  ↓
Step 5: 行动建议 → 优先级排序（P0保护机制/P1引导优化）
```

## 五、核心结论：影响留存的四条主线

```mermaid
graph LR
    subgraph 胜负情绪线 [胜负情绪线]
        A1[连败长度] --> A2[胜率]
        A2 --> A3[干预: 连败打断<br/>匹配保护]
    end
    
    subgraph 经济压力线 [经济压力线]
        B1[破产状态] --> B2[银子变化]
        B2 --> B3[干预: 破产兜底<br/>房间推荐]
    end
    
    subgraph 投入度线 [投入度线]
        C1[对局数] --> C2[首局体验]
        C2 --> C3[干预: 首局引导<br/>对手验证]
    end
    
    subgraph 稳定性线 [稳定性线]
        D1[多次登录] --> D2[逃跑率]
        D2 --> D3[干预: 崩溃修复<br/>体验优化]
    end
```

| 主线 | 核心指标 | 产品干预方向 |
| ---- | ---- | ---- |
| **胜负情绪线** | 连败长度、胜率 | 连败打断机制、匹配保护、新手配牌优化 |
| **经济压力线** | 破产状态、银子净变化 | 破产兜底、房间智能推荐、倍数上限限制 |
| **投入度线** | 首日对局数、首局体验 | 首局引导强化、新手礼包加厚、首局对手构成验证 |
| **稳定性线** | 多次登录、逃跑率 | 客户端崩溃修复、操作体验优化、逃跑罚没调整 |
