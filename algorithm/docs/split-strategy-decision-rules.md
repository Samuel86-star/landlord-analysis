# 拆牌策略决策规则（顺子连对优先 vs 飞机炸弹优先）

根据手牌点数分布，在「顺子/连对优先」与「飞机/炸弹优先（贪心）」之间自动选择一种策略，只跑一套拆牌，在保证质量的前提下减少计算。

---

## 一、统计范围约定

- **顺子区**：点数 3~A（`Rank.THREE` ~ `Rank.ACE`，共 12 个点数），不含 2 和王。顺子、连对、飞机只在这些点数上成立。
- **计数**：`count[r]` = 点数 `r` 的手牌张数，`r` 使用 `Rank.ordinal()` 作为下标。

---

## 二、从 `count` 派生的特征（仅顺子区 3~A）

在顺子区 12 个点数上统计，不包含 2 和王。

| 特征名 | 含义 | 计算方式 |
|--------|------|----------|
| **maxStraightLen** | 顺子潜力 | 在 3~A 顺序上，满足「每个点至少 1 张」的最长连续区间长度。若 ≥5 表示能出至少一条顺子。 |
| **maxConsecutivePairsLen** | 连对潜力 | 在 3~A 顺序上，满足「每个点至少 2 张」的最长连续区间长度。若 ≥3 表示能出至少一条连对。 |
| **maxPlaneLen** | 飞机潜力 | 在 3~A 顺序上，满足「每个点至少 3 张」的最长连续区间长度。若 ≥2 表示能出至少一架飞机。 |
| **numTriples** | 三张点数个数 | 顺子区内 `count[r] >= 3` 的点数 r 的个数（即至少 3 张的点数个数）。 |
| **numBombs** | 炸弹个数 | 顺子区内 `count[r] >= 4` 的点数个数（每个点数最多计 1 个炸弹）。 |
| **numPairsInStraightRange** | 对子点数个数 | 顺子区内 `count[r] >= 2` 的点数个数。 |
| **totalCardsInStraightRange** | 顺子区总张数 | 顺子区 12 个点数的 `count` 之和。 |

以上均为非负整数；顺子区外的 2 和王仅影响「王炸、2 的炸弹」等，不参与上述特征。

---

## 三、决策规则（按优先级判断）

按下列顺序判断，命中第一条即返回对应策略；若都不命中则走**默认策略**。

1. **强顺子/连对 + 弱飞机**
   - 条件：`maxStraightLen >= 7` 或 `maxConsecutivePairsLen >= 5`，且 `maxPlaneLen <= 1` 且 `numTriples <= 1`。
   - 决策：**顺子/连对优先**。长顺子或长连对价值高，且几乎组不出飞机，优先保留线性牌型。

2. **可组飞机且会破坏顺子**
   - 条件：`maxPlaneLen >= 2`（能出飞机），且 `maxStraightLen >= 6` 或 `maxConsecutivePairsLen >= 4`。
   - 决策：**飞机/炸弹优先（贪心）**。先出飞机/炸弹容易把顺子拆散；本规则下认为飞机收益更大，选贪心。

3. **顺子/连对潜力明显优于飞机**
   - 条件：`maxStraightLen >= 6` 或 `maxConsecutivePairsLen >= 4`，且 `numTriples <= 1`。
   - 决策：**顺子/连对优先**。三张/炸弹少，优先保顺子、连对。

4. **飞机/炸弹结构明显**
   - 条件：`numTriples >= 3` 或 `numBombs >= 2`，且 `maxStraightLen < 6` 且 `maxConsecutivePairsLen < 4`。
   - 决策：**飞机/炸弹优先（贪心）**。多三张或多炸弹，且顺子/连对潜力一般，用贪心更合适。

5. **有长顺子且无多三张**
   - 条件：`maxStraightLen >= 5` 且 `numTriples <= 2`。
   - 决策：**顺子/连对优先**。避免贪心把长顺拆成短牌型。

6. **有飞机潜力且顺子不长**
   - 条件：`maxPlaneLen >= 2` 且 `maxStraightLen <= 5`。
   - 决策：**飞机/炸弹优先（贪心）**。

7. **默认**
   - 条件：以上均不满足。
   - 决策：**飞机/炸弹优先（贪心）**。与 `PlaneBombFirstSplitAlgorithm` 行为一致，保证下限。

---

## 四、阈值汇总（便于调参）

| 阈值 | 建议值 | 含义 |
|------|--------|------|
| 长顺子 | 7 / 6 / 5 | 顺子潜力 ≥ 该值时可优先顺子/连对（视其他条件）。 |
| 长连对 | 5 / 4 | 连对潜力 ≥ 该值时可优先顺子/连对。 |
| 飞机潜力 | 2 | 顺子区连续三张长度 ≥2 即认为可出飞机。 |
| 三张点数 | 1 / 2 / 3 | 顺子区内 count≥3 的点数个数，用于判断「弱飞机」或「多三张」。 |
| 炸弹个数 | 2 | 顺子区内炸弹 ≥2 且顺子一般时走贪心。 |

---

## 五、与实现的对应关系

- **顺子/连对优先** → 使用 `StraightFirstSplitAlgorithm.split(hand)`（先顺子、连对，再三张/对子/单牌，最后炸弹）。
- **飞机/炸弹优先（贪心）** → 使用 `PlaneBombFirstSplitAlgorithm.split(hand)`（王炸→炸弹→飞机→四带二→顺子→连对→三带→对子→单）。

实现上由 `SplitterAlgorithmFactory` 根据 `HandCardUtils.buildRankCountsFromHand(hand)` 得到 `count`，在顺子区上计算特征并按第三节顺序判断，再通过 `getSplitter(hand)` 返回对应算法，`split(hand)` 只执行该算法的一套拆牌。
