# old2/Type0 发牌做牌模拟器

> `old2_type0_sim.py` —— 把线上经典房 `old2`/Type0 的发牌做牌逻辑用 Python 1:1 复刻，
> 用来**快速模拟、量化各种改法的效果**，不需要 C++ 编译环境，**Python 3 开箱即用**。
> 适用：产品/运营/分析快速评估"做牌调整后，玩家手牌会变成什么样"。

## 一、快速开始

```bash
# 1) 扫描所有改法对比（最常用，一眼看各改法的炸弹/手数/大牌）
py -3 old2_type0_sim.py sweep --n 10000

# 2) 跑单个改法（例如"去 MatchBomb"）
py -3 old2_type0_sim.py run --fix no-bomb --n 20000

# 3) 看某个改法的牌型构成（牌长什么样：顺子/连对/飞机/三/对/单 各多少）
py -3 old2_type0_sim.py structure --fix no-bomb --n 10000

# 4) 跑内置测试（机制验证 + bug 复现 + 采样）
py -3 old2_type0_sim.py test

# 5) 看帮助
py -3 old2_type0_sim.py
```

> 不带参数会打印帮助。所有命令都支持 `--seed`（固定随机种子，结果可复现、改法间可比）。

## 二、模拟场景

固定为**经典初级房新手保护**形态（线上 ~99% 走这个）：

- 1 真人 + 2 机器人；
- **真人为庄（FirstChair）**，两个机器人为闲（OtherChair）；
- 做牌配置 = `makedeal.json` 的 `old2`（`BeginMakeNum=12`、各 `First/OtherChair*` 阈值、`BigCardsTo=2`）；
- Type0 流程：洗牌 → 前 12 张固定发 → 体检（手数/炸弹/大牌）→ `DoMakeDeal` 五轮六步菜单补牌 → 填空。

> 想模拟其它形态（多真人、不优待真人等），需改 `deal()` 的 `player_types` / `is_fix_banker` 参数（见代码）。

## 三、改法清单（`--fix`）

| `--fix` | 含义 | 是否动代码 |
|---|---|---|
| `baseline` | 现状（含 bug，全菜单）——**改前基线** | — |
| `no-bomb` | 做牌菜单去掉 `MatchBomb`（不主动凑炸弹） | 改代码 |
| `bomb-last` | `MatchBomb` 降到菜单最后（保留但最低优先级） | 改代码 |
| `fix-bug` | 修"第二轮无条件做牌"bug（只续做第一轮触发过的家） | 改代码 |
| `fix-bug-no-bomb` | 修 bug + 去 `MatchBomb` | 改代码 |

> ⚠️ `old2`/Type0 下，`makedeal.json` 能调的只有 `BeginMakeNum`、6 个 `First/OtherChair*` 阈值、`BigCardsTo`；
> **做牌菜单顺序（含凑炸弹的 `MatchBomb`）和那个 bug 是代码写死的，配置改不了**。所以降炸弹的改法都得改代码。

## 四、输出指标怎么看

| 指标 | 含义 | 怎么判断好坏 |
|---|---|---|
| **炸弹** | 单家平均持有炸弹数（4 张同点 + 王炸） | 越接近"纯随机 ≈ 0.19"越自然；现状 0.42（翻倍） |
| **手数** | 单家平均几手能出完（贪心拆牌估计） | **越少越好打**；现状 6.05、纯随机 7.50 |
| **大牌** | 单家平均持有 2/王 张数 | 控制力；做牌不改变总量（≈1.89） |
| **庄炸/闲炸** | 庄（真人）/闲（机器人）的炸弹均值 | 看庄家优待程度 |

`structure` 子命令的牌型构成：`rocket` 王炸 / `bomb` 炸弹 / `plane` 飞机 / `seq_pair` 连对 / `straight` 顺子 / `triple` 三张 / `pair` 对子 / `single` 单牌（单家平均个数）。**牌型越连贯（顺/连对/飞机多）、单牌越少，手感越顺**。

## 五、主要结论（基线下）

- **去 `MatchBomb`**：炸弹 0.42 → **0.15（-65%）**，手数基本不涨（6.05→6.25），牌型反而更连贯（顺/连对/飞机变多，单牌变少）——**好打但不给炸弹，正好命中"贴近真实"的目标**。
- **修 bug** 效果有限（0.42→0.38），证明炸弹主因是 `MatchBomb` 在菜单第 2 位，不是 bug。
- **调参**（`BigCardsTo`/`BeginMakeNum`/阈值）降不了炸弹，有的方向反而让炸弹更多。

## 六、依赖与定位

- **依赖**：Python 3 标准库（`random`/`argparse`），无第三方包。
- **定位**：1:1 复刻线上 `old2`/Type0（含已知 bug）的**研究用模拟器**，非生产代码。
- **参照源**：同目录 `previous/`（线上发牌代码副本 + `makedeal.json`），便于核对一致性。
