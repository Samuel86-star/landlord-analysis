# Type1 发牌拼牌模拟器

> `old2_type1_sim.py` —— 把线上 `MakeDealType=1`（CouPaiStrategy 拼牌）的发牌逻辑用 Python 复刻，
> 用来**穷举 `makedeal.json` 配置（CouPaiStrategy / BeginMakeNum / BeginSelectBanker / TargetValue / TargetRound），找最接近经典发牌的组合**。
> Python 3 标准库，无第三方依赖。适用：产品/研发评估"Type1 配置调成什么样，手牌最贴近经典"。

## 一、快速开始

```bash
# ★推荐组合（最均衡）：收对策略 + 轻干预（b14 sel17）
py -3 old2_type1_sim.py run --coupai with-pair --begin 14 --select 17 --tv 999 --tr 10 --n 10000

# 一键扫描各策略（默认 begin=10/select=15/tv=0.6/tr=4）
py -3 old2_type1_sim.py sweep --n 3000

# 寻经典组合三维扫描：策略 × begin × select，输出 Pareto 前沿 + 近经典推荐
py -3 -c "import old2_type1_sim as m; m._test_grid_t1()"
```

> 所有命令支持 `--seed`（固定随机种子，可复现、可比）。

## 二、核心结论（纠正先前误判）

> ⚠️ 早先版本曾结论"Type1 炸弹下限 0.33，达不到经典 0.19"——**这个结论是错的**。
> 原因：当时只扫了"带对子(2)补牌"的聚集型策略。补全散牌型策略后，**Type1 完全能压到经典 0.19 以下**。

**Type1 凑炸弹的充要条件（三 AND，源 `zgdatbl.cpp:4041` + `MakeDealHelper.cpp:849-869`）：**
1. 选中的 `CouPaiStrategy` 里有 `13`（cgBOMB_CARD）——这是**唯一**把 3 张补成 4 张成炸的分支；
2. `bNeedMakeDeal==true`（`手数 > TargetRound` 或 `牌力 < TargetValue`）；
3. 手里有三张 + 剩余牌有第 4 张。

**所以杠杆不是"有没有 13"，而是整个策略的聚集/散开倾向：**

| 牌型码 | 含义 | 对炸弹 | 对手数 |
|---|---|---|---|
| `2` 对 / `3` 三 | 单→对、对→三（**聚集**） | ↑↑ 顶高 | ↓↓ 降低 |
| `4` 顺 / `5` 连对 / `6` 飞机 | 拉牌成型（**散开**） | ↓↓ 压低 | ↑ 升高 |
| `13` 炸 | 三→炸 | ↑↑↑ | ↓ |

**关键断崖**：策略里一旦带 `2`（对子补），炸弹会从 ~0.15 一脚跳到 ~0.30，中间几乎无过渡。
- **`BeginMakeNum` 填缝**：begin 越大 → 拼牌越少 → 聚集策略的炸弹从 0.30 向自然 0.19 回落。
- **`BeginSelectBanker` 控覆盖率**：15=只拼一段(余下随机填)、17=补满所有空位（线上 robot/newuser 用 17）；sel 越大 → 手数越低但炸弹越高。

## 三、推荐组合（N=10000，手数 = t1拆口径，与 CLI 输出一致）

目标：炸弹≈自然 0.19（不给炸弹）、手数尽量低（好打）、庄闲均衡。

| 定位 | CouPaiStrategy | begin | sel | 炸弹 | 手数 | 庄闲差 |
|---|---|---|---|---|---|---|
| **★推荐（最均衡）** | `with-pair [4,6,5,2,3]` | 14 | 17 | **0.203** | **6.50** | +0.001 |
| 炸弹最准 0.19 | `with-pair [4,6,5,2,3]` | 13 | 15 | 0.185 | 7.05 | -0.004 |
| 不收对（最少炸） | `no-pair [4,5,3,6]` | 13 | 15 | 0.180 | 7.09 | +0.024 |
| 全量均衡 | `[4,5,6,3,2]` | 14 | 15 | 0.196 | 7.21 | +0.009 |
| 对照：纯随机 | — | — | — | 0.194 | 7.80 | — |
| 对照：线上 default | `[4,13,6,5,3,2]` | 10 | 15 | ~0.54 | ~6.3 | ~0 |

**★ `with-pair [4,6,5,2,3]` + b14 sel17**：顺→飞机→连对→对→三（**收对**）。b14 sel17 = 14 随机 + 3 张拼满，干预最轻 → 炸弹 0.203（贴经典 0.19）、手数 6.50（好于自然 7.8）、庄闲差 0.001。

**命名**：`with-pair` = 策略带对子码 `2`（收对 → 成型好打 → 炸弹略高）；`no-pair` = 不带 `2`（不收对 → 少炸偏自然，= 线上 `new`）。两者就差这个 `2`。

**tv/tr**：`tv=999/tr=10`（恒走策略环，最可控）≈ `tv=0.6/tr=4`；避免 `tv=0.6/tr=10`（need=false 走更聚集补对分支，炸弹升 0.29）。固定 `tv=999/tr=10` 即可。

## 四、与 Type0 控制流对比

经典玩法做牌降炸弹有两条路（本表用 **t0拆口径**，跨类型可比；§三 用 t1拆与 CLI 对齐，同配置 t1拆手数比 t0拆高 ~0.4）：

| 路线 | 改动 | 炸弹 | 手数 | 说明 |
|---|---|---|---|---|
| **Type0 control-flow + bmn10** | **改代码**（菜单顺序）+ 改配置 | **0.196** | **5.82** | 炸弹&手数双优 |
| **Type1 with-pair + b14 sel17** | **只改配置**（不改代码） | 0.202 | 6.17 | 免改代码，手数略高 |

- 能改代码 → Type0 控制流双指标都更好（0.196 炸 / 5.82 手），全局最优。
- 只能改配置 → Type1 `with-pair b14 sel17` 到经典级炸弹（0.202），手数 6.17（仍好于自然 7.5）。
- Type1 天花板：要 6 手必聚集 → 炸弹≥0.25；要 0.19 炸 → 手数≥7。**Type1 给不出"6 手 @ 0.19 炸"**，那是 Type0 控制流的专属。

## 五、输出指标

| 指标 | 含义 | 判断 |
|---|---|---|
| 炸弹 | 单家平均炸弹数（4 张同点 + 王炸） | 越接近纯随机 0.194 越自然 |
| 手数 | 单家平均几手出完（贪心拆牌估计） | 越少越好打；纯随机 7.80(t1拆)/7.50(t0拆) |
| 庄炸/闲炸 | 庄(真人)/闲(机器人)炸弹均值 | 看庄闲是否均衡（防真人被欺负） |

## 六、定位与局限

- **依赖**：Python 3 标准库（`random`/`argparse`），无第三方包。
- **复刻度**：拼牌 `MakeDeal_ComposeCard` 1:1；拆牌用贪心近似（不递归），故**手数是相对值**（绝对值可能与真实打法有偏差，但跨配置排序可靠）；炸弹计数精确。
- **口径**：手数有 t1拆（本模拟器 CLI 默认）与 t0拆（`old2_type0_sim` 的算法）两版，同配置 t1拆比 t0拆高 ~0.4，排序一致；跨 Type0/Type1 比较时统一用 t0拆。
- **参照源**：同目录 `previous/`（`zgdatbl.cpp` Type1 分支 `3993`、`MakeDealHelper.cpp` `MakeDeal_ComposeCard 771`、`makedeal.json`）。
