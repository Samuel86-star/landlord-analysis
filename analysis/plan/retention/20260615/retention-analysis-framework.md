# 留存分析框架：视角与相关指标

> 本文档提炼留存分析的核心视角、关键指标及其与留存的相关性规律，作为后续分析的速查手册。
> 基于 2026-06-11 重构后的数仓表结构更新。

---

## 框架概览

```text
输入层：新增用户数据
    ↓
分析视角：用户属性 / 投入度 / 胜负体验 / 经济状态
    ↓
指标层级：高相关性指标 / 中等相关性指标 / 背景指标
    ↓
输出层：高危信号组合 / 干预优先级
```

---

## 一、分析视角（四大维度）

| 视角 | 核心问题 | 分析子维度 |
| ---- | ---- | ---- |
| **用户属性** | "谁"更容易留存/流失？ | 渠道分类、设备类型（iOS/Android）、客户端版本（Cocos-Lua/Cocos-Creator）、注册时段 |
| **投入度** | "玩得多少"影响留存？ | 首日对局数、首日总时长、玩法数量、是否跨玩法 |
| **胜负体验** | "输赢感受"如何影响留存？ | 首日胜率、连胜/连败长度、首局胜负、角色胜率差异（地主/农民）、角色偏好、炸弹/春天数 |
| **经济状态** | "银子压力"是否驱动流失？ | 银子净变化、破产状态、高倍局输赢、携银与房间匹配度、房间底注门槛 |

---

## 二、留存相关指标（影响力金字塔）

### 2.1 高相关性指标（直接影响留存）

| 指标 | 分组方式 | 留存规律（已验证） | 数据来源表 |
| ---- | ---- | ---- | ---- |
| **首日对局数** | 0局/1局/2-5局/6-10局/10+局 | 存在最优区间（6-10局），过少未形成习惯，过多可能疲劳 | `dws_app_silvergame_stat` + `dws_app_scoregame_stat` |
| **首日胜率** | \<30%/30-50%/50-70%/70%+ | 胜率<30%流失风险极高，胜率与留存正相关 | `dws_app_silvergame_stat` |
| **连败长度** | 0-1/2-3/4-5/5+ | 连败≥3局流失概率急剧上升，关键流失预警信号 | `dws_app_silvergame_stat` |
| **银子净变化** | 巨亏(\<-5万)/大亏(-5万~-1万)/小亏(-1万~0)/小赚(0~1万)/大赚(1万~5万)/巨赚(>5万) | 净亏损用户留存显著低于盈利用户 | `dws_app_silvergame_stat` |
| **是否破产** | 银子谷值≤最低房间门槛 | 破产后直接退出比例高，经济系统兜底的核心指标 | `dws_app_silvergame_stat` |
| **高倍局输赢** | 仅赢高倍/仅输高倍/有赢有输 | 输高倍（>24x）是流失高危信号，赢高倍留存提升 | `dws_app_allgame_stat` |

### 2.2 中等相关性指标（需分场景分析）

| 指标 | 分组方式 | 留存规律 | 数据来源表 |
| ---- | ---- | ---- | ---- |
| **首日平均倍数** | ≤6/6-12/12-24/24+ | 倒U型关系，12-24x留存最优（非越高越好） | `dws_app_allgame_stat` |
| **首局胜负** | 胜/负 | 首局胜率预期偏高（新手配牌），首局负留存显著低 | `dws_ddz_firstday_game` |
| **逃跑次数** | 0/1/2/3+ | 逃跑反映挫败感，逃跑率>15%留存极低 | `dws_app_silvergame_stat` |
| **房间底注/门槛** | 极低/低/中/高 | 越高的底注破产风险越大，对新手留存压力越大 | `dws_app_allgame_stat` |
| **角色偏好** | 纯农民/偏好农民/均衡/偏好地主 | 地主体验方差大（大输大赢），偏好地主的用户留存与经济变化强绑定 | `dws_ddz_firstday_game` |
| **玩法选择** | 单玩法/多玩法 | 多玩法探索用户留存更高（兴趣广） | `dws_app_gamemode_active` |

### 2.3 弱相关性/背景指标（区分用户类型）

| 指标 | 作用 | 数据来源表 |
| ---- | ---- | ---- |
| **渠道分类** | 区分渠道质量，非产品问题 | `dws_dq_app_daily_reg` + `dq_channel_category_map` |
| **客户端版本** | 识别稳定性差异（多次登录=崩溃信号） | `dws_dq_app_daily_reg` |
| **注册时段** | 区分用户画像（夜间玩家/白天玩家），时段本身无因果 | `dws_dq_app_daily_reg` |
| **炸弹数、春天发生率** | 游戏体验细节，需分玩法看（癞子天然高倍） | `dws_app_allgame_stat` |

## 三、流失高危信号组合

| 组合特征 | 留存预期 | 优先级 |
| ---- | ---- | ---- |
| **连败≥3 + 银子亏损 + 高倍局输** | 极低（\<10%） | P0 |
| **首局负 + 地主角色 + 高倍局** | 低（\<15%） | P0 |
| **0局/1局 + 多次登录（≥3）** | 低（崩溃/掉线） | P0 |
| **破产 + 不再对局** | 极低 | P1 |
| **胜率\<30% + 对局数少（≤2）** | 低 | P1 |

## 四、分析路径建议

```text
Step 1: 留存概览 → 建立基线（渠道/设备/客户端分组留存）
  ↓
Step 2: 高相关性指标分组 → 确认规律（胜率/连败/破产/高倍局）
  ↓
Step 3: 多维交叉 → 定位高危组合（连败×破产×高倍输）
  ↓
Step 4: 专项下钻 → 找根因（1局用户对手构成/客户端稳定性）
  ↓
Step 5: 行动建议 → 优先级排序（P0保护机制/P1引导优化）
```

## 五、核心结论：影响留存的四条主线

| 主线 | 核心指标 | 产品干预方向 |
| ---- | ---- | ---- |
| **胜负情绪线** | 连败长度、胜率 | 连败打断机制、匹配保护、新手配牌优化 |
| **经济压力线** | 破产状态、银子净变化 | 破产兜底、房间智能推荐、倍数上限限制 |
| **投入度线** | 首日对局数、首局体验 | 首局引导强化、新手礼包加厚、首局对手构成验证 |
| **稳定性线** | 多次登录、逃跑率 | 客户端崩溃修复、操作体验优化、逃跑罚没调整 |

## 六、数仓表结构（2026-06 重构版）

### 6.1 账号域

| 表名 | 粒度 | 说明 |
| ---- | ---- | ---- |
| `dws_dq_daily_reg` | uid × reg_date | 全平台用户注册信息 |
| `dws_dq_daily_login` | uid × login_date | 每日登录聚合（首次/最后/最频繁渠道、分端、app_code） |
| `dws_dq_app_daily_reg` | uid | APP端注册用户宽表（预关联登录+渠道分类） |

### 6.2 游戏域

| 表名 | 粒度 | 用途 |
| ---- | ---- | ---- |
| `dws_app_game_active` | uid × dt × app_id | **留存 flag 计算**（任意玩法有对局即活跃） |
| `dws_app_gamemode_active` | uid × dt × app_id × play_mode | **同玩法留存 flag**（需在同一 play_mode 有对局） |
| `dws_app_silvergame_stat` | uid × dt | 银子玩法金流+参与度（play_mode 1,2,3,7） |
| `dws_app_scoregame_stat` | uid × dt | 积分玩法参与度+胜负（play_mode 4,5,6） |
| `dws_app_allgame_stat` | uid × dt × play_mode | 全玩法体验分析（倍数/炸弹/胜率） |
| `dws_ddz_daily_game` | resultguid × uid | 经典斗地主对局明细（play_mode 1~6） |
| `dws_ddz_firstday_game` | resultguid × uid | 经典斗地主首日对局明细（同字段，仅 reg_date = dt） |
| `dws_crazyddz_daily_game` | resultguid × uid | 疯狂斗地主对局明细（play_mode=7，多轮聚合） |

### 6.3 表选用决策树

```text
需要留存 flag？
  ├── 整体留存（任意玩法） → dws_app_game_active
  └── 同玩法留存 → dws_app_gamemode_active
需要归因指标？
  ├── 银子金流 → dws_app_silvergame_stat
  ├── 积分参与度 → dws_app_scoregame_stat
  └── 玩法体验（倍数/炸弹） → dws_app_allgame_stat
需要用户属性？
  └── dws_dq_app_daily_reg（含渠道分类、客户端版本、设备类型）
```
