## 四、magnification 翻倍次数 N × 局序 × 胜率

### 4.1 倍数机制说明（user 2026-06-26 反馈修订）

v0.1 草稿最初用 `[0-8, 9-16, 17-32, 33-64, 65+]` raw `magnification` 桶做交叉，**这是错的**。经 user 提示：斗地主**底分默认 3 分**，每打出一个炸弹/王炸/春天等"翻倍事件"就 ×2，**最终理论倍数 = 3 × 2^N**。

实测 06-18~24 全量 6,885,228 行 `magnification`：

| 系列 | 命中 | 占比 | 含义 |
| ---- | ---- | ---- | ---- |
| **3 × 2^N**（N=0~15） | 6,529,705 | **94.84%** | **默认底分=3 的经典斗地主** |
| 1 × 2^N（底分=1） | 105,567 | 1.53% | 底分=1 的特殊房间 |
| 18 × 2^N（底分=18） | 192,041 | 2.79% | 底分=18 的房间 |
| 其他异常（9/27/81/147456/196608 等） | 57,915 | 0.84% | 明牌倍数调整或脏数据 |

→ 94.84% 严格符合 3×2^N，证实 user 反馈正确。**本报告以下分析统一用"翻倍次数 N"作为倍数维度**（仅看 3×2^N 主序列，3,562/3,564 = 99.94% 命中；2 行异常剔除）。

## 五点五、N 翻倍次数的组成拆解（user 2026-06-26 追问补充）

### 5.5.1 字段结构

`ddz_daily_game_raw.magnification_subdivision`（JSON）记录 N 的翻倍来源明细：

```json
{
  "public_bet": {
    "initial_bet": 1,                // 初始底分,固定 1
    "bomb_bet": 2,                   // 炸弹(每打 1 个 ×2),取 1/2/4/6/8/10...
    "grab_landlord_bet": 3,          // 抢地主(基础 3,每抢 1 次 ×2),取 3/6/12/24
    "complete_victory_bet": 1        // 春天/反春天(1=无,2=有)
  },
  "behavior_bet": {                  // 玩家个人加倍
    "farmer1": 1, "farmer2": 1, "landlord": 1  // 1=未加倍,2=已加倍
  }
}
```

**N 的合成公式**（实测 06-25 全量 933,083 行 3×2^N 真人牌局验证）：

```
magnification = 3 × bomb_bet × (grab_landlord_bet / 3) × complete_victory_bet × max(behavior_bet)
```

**事实观察（user 洞察"倍数决定因素不只炸弹数"被数据证实）**：

- **N=0 全是混合**（无任何单一翻倍来源,纯基础局）—— 113,003 行,占 97.5%
- **N=1 翻倍来源最分散**：15,743 行（7.6%）来自"玩家个人加倍"（叫完地主后单个玩家 ×2）、7,918 行（3.8%）来自"抢地主"、6,877 行（3.3%）来自"春天"—— 这三个非炸弹来源合计 **30,538 行(14.7%)**,**远超过 N=1 中炸弹主导的 0 行**！
- **N=2~4 主要由炸弹推动**(36-87%),但仍有 10-15% 来自"抢地主"或"个人加倍"等
- **N=5+ 几乎全部由炸弹推动**（>96%）—— 极端倍数主要靠"打多个炸弹"(包括连炸/王炸)
- **抢地主主导上限是 N=2~3**(最多 16,142 行),与叫牌机制限制(最多抢 2 次)一致
- **春天是"小众"事件**：N=4 时仅 3 行,N=5+ 完全没有
- **个人加倍** 是 N=1~2 的常见来源（N=1 占 7.6%）,但 N=3+ 几乎消失

### 5.5.3 对分析的影响

- **v0.1 / v0.2 报告里的"王炸在中等 N(2~3) 增益最大 (+15pp)"** 实际上是**"王炸 + 炸弹组合"** 共同作用：N=2~3 的牌局中炸弹主导占比 36-70%,王炸玩家更容易"凑出炸弹"
- **N=1 时王炸的"陷阱"现象**（王炸 64% < 无王 76%,见报告第五章）需要更细分析：N=1 牌局里"王炸"成分可能比"炸弹"成分更重要,但 N=1 的牌力差异更大
- **后续 v1.0 复跑**应进一步按 `(bomb_bet, grab_bet, cv, behavior)` 4 维组合分析胜率,而不是只看 N 总数

## 七、关键发现总结

### 7.1 新手保护期 vs 失效期的清晰拐点

| 维度 | 局 1-3（保护期） | 局 4（失效期） |
| ---- | ---- | ---- |
| 王炸率 | 36-43% | **6.64%** |
| 地主占比 | 83-89% | 46% |
| 胜率 | 77-93% | 44% |
| 平均输赢 | +2,195 ~ +2,562 | **-262** |
| 单王胜率 | 26-60%（陷阱） | 43%（正常） |

→ **第 4 局是新手保护期的"毕业"标志**，3 局是保护配牌的核心窗口。

### 7.2 配牌机制：把王炸+好牌集中在少数玩家

- 王炸玩家 70%+ 是地主（**配牌倾斜**）
- 王炸组牌力均值 65-78（最高）
- 王炸组终牌力 100-105（底牌加成后），vs 无王组 49-69

### 7.3 magnification 桶 × 王情况 的非单调关系

- **低倍数（0-8）王炸反而是负担**（60% < 无王 76%）
- **中等倍数（9-32）王炸是最强优势**（+15pp）
- **高倍数（65+）所有王情况都低**（不洗牌风险）

### 7.4 单王陷阱（待解释）

- 单王在所有局序、所有倍数桶中**胜率都是最低的**
- 可能原因：单王玩家牌力"卡中间"（15-20 牌力），被无王的高牌力或王炸碾压
- 也有可能"单王=配牌失败"的信号（配牌想凑王炸没凑成）
