## 七、关键发现总结

### 7.1 新手保护期 vs 失效期的清晰拐点

| 维度 | 局 1-3（保护期） | 局 4（失效期） |
| ---- | ---- | ---- |
| 王炸率 | 36-43% | **6.64%** |
| 地主占比 | 83-89% | 46% |
| 胜率 | 77-93% | 44% |
| 平均输赢 | +2,195 ~ +2,562 | **-262** |
| 单王胜率 | 26-60%（陷阱） | 43%（正常） |

→ **第 4 局是新手保护期的"毕业"标志**，3 局是保护配牌的核心窗口。

### 7.2 配牌机制：把王炸+好牌集中在少数玩家

- 王炸玩家 70%+ 是地主（**配牌倾斜**）
- 王炸组牌力均值 65-78（最高）
- 王炸组终牌力 100-105（底牌加成后），vs 无王组 49-69

### 7.3 magnification 桶 × 王情况 的非单调关系

- **低倍数（0-8）王炸反而是负担**（60% < 无王 76%）
- **中等倍数（9-32）王炸是最强优势**（+15pp）
- **高倍数（65+）所有王情况都低**（不洗牌风险）

### 7.4 单王陷阱（待解释）

- 单王在所有局序、所有倍数桶中**胜率都是最低的**
- 可能原因：单王玩家牌力"卡中间"（15-20 牌力），被无王的高牌力或王炸碾压
- 也有可能"单王=配牌失败"的信号（配牌想凑王炸没凑成）
