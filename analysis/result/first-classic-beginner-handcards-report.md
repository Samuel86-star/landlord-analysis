# 首次经典初级房玩家前 3 局手牌分析报告

> **报告说明**
>
> - **时间窗口**：注册与对局均为 `2026-06-18 ~ 2026-06-24`（7 日固定窗口，不向 06-25 追踪）
> - **Cohort**：首次经典斗地主对局发生在经典玩法初级房 `4484` 或 `12074`、且发生在注册当日的玩家（robot != 1，play_mode 1-6）
> - **数据来源**：`tcy_temp.dws_ddz_daily_game`、`tcy_temp.dws_dq_app_daily_reg`（经 `py/sr_exec.py` 的 `query_paged` 分页拉取，共 21,025 行明细）
> - **牌力可信前提**：`card_power` 算法已于 2026-06-15 修复，本窗口在其后，`card_power` / `card_power_final` 可信
> - **手牌功能上线时间**：上游"手牌上报"功能 2026-06-25 早上才上线，本报告窗口（06-18~24）**早于上线时点**，故 `extend_content.card_info.hand_cards` / `bottom_cards` 在窗口内 0 覆盖是预期的（已实测 03-15~06-24 全部 0 覆盖，06-25 覆盖 92.5%）。下一版报告将用含 06-25~07-01 的窗口重做手牌结构模块
> - **分析性质**：纯描述性，只呈现可观察事实与机制字段，不做因果推断
> - **范围调整**：框架原计划第七章"手牌结构解析"因本窗口手牌功能未上线无法落地，改用 `card_power` 节点里表文档未记录的 `bomb_cnt` / `bomb_final`（持有炸弹数）替代分析
> - **配套产出**：`py/first-classic-beginner/output/*.csv`（各模块聚合结果）

## 四、配牌机制

**配牌组（`shuffle_type=201` 新手保护 / `card_id>0` 其他牌库 / `card_id=0` 随机）**：

| 局序 | 配牌组 | 记录数 | 占比 | avg_card_power | reshuffle_pass_rate |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 1 | A: 新手保护配牌 | 7,483 | **99.39%** | **55.35** | 0.0000 |
| 1 | C: 随机/无牌库 | 46 | 0.61% | 21.54 | 0.0000 |
| 2 | A: 新手保护配牌 | 6,862 | 98.80% | 51.09 | 0.0000 |
| 2 | C: 随机/无牌库 | 83 | 1.20% | 14.92 | 0.0000 |
| 3 | A: 新手保护配牌 | 5,681 | **86.72%** | 51.45 | 0.0000 |
| 3 | C: 随机/无牌库 | 870 | 13.28% | 25.83 | 0.0000 |

**事实观察**：

- **配牌保护覆盖逐局递减**：第 1 局 99.39% → 第 2 局 98.80% → 第 3 局 86.72%。第 3 局约 13% 进入真实随机发牌
- **保护配牌牌力显著高于随机**：seq1 保护配牌 `avg_card_power=55.35` vs 随机 21.54（差 33.8）；seq2 差 36.2；seq3 差 25.6。机制层面 `shuffle_type=201` 是新手保护机器人
- 第 1/2 局没有出现"其他牌库配牌"（B 组），全部是保护配牌或随机；第 3 局情况类似（B 组 0 记录）
- `reshuffle_pass_rate`（`is_pass`）三局都为 0，说明本窗口样本里 `is_pass` 全部为 false（重洗牌机制未触发或字段全 false，需查机制）

## 五、持有炸弹分析（替代手牌结构）

因 `hand_cards` 数仓缺失，本节用 `bomb_cnt`（初始手牌持有炸弹数）/ `bomb_final`（算底牌后持有炸弹数，地主含底牌）描述"持有炸弹"维度。

**整体（不分角色）**：

| 局序 | 用户数 | bomb_hold_rate | avg_bomb_cnt | avg_bomb_final |
| ---- | ---- | ---- | ---- | ---- |
| 1 | 7,529 | 0.0000 | 0.000 | 0.237 |
| 2 | 6,945 | 0.0009 | 0.001 | 0.247 |
| 3 | 6,551 | 0.0008 | 0.001 | 0.242 |

**分角色**：

| 局序 | 角色 | 用户数 | avg_bomb_cnt | avg_bomb_final |
| ---- | ---- | ---- | ---- | ---- |
| 1 | 地主(1) | 6,268 | 0.0 | **0.285** |
| 1 | 农民(2) | 1,261 | 0.0 | 0.0 |
| 2 | 地主(1) | 6,044 | 0.0 | 0.283 |
| 2 | 农民(2) | 901 | 0.006 | 0.006 |
| 3 | 地主(1) | 5,499 | 0.0 | 0.288 |
| 3 | 农民(2) | 1,052 | 0.003 | 0.003 |

**事实观察**：

- **初始手牌几乎不持有炸弹**：`bomb_cnt` 三局全 0（极少数农民 0.006）。结合配牌分析 99% 是新手保护配牌，保护配牌机制层面不发初始炸弹
- **底牌偶尔补炸弹**：地主 `bomb_final` ≈ 0.285，即约 28.5% 地主在算底牌后持有至少 1 个炸弹（农民无底牌，`bomb_final=0`）
- 这与 `bomb_bet`（打出炸弹数，框架 6.3 字段）是不同维度——`bomb_cnt` 是"持有"，`bomb_bet` 是"打出"；本报告未聚合 `bomb_bet`

## 六、牌力与胜负一致性

**按牌力桶 × 局序的胜率与输赢**：

| 局序 | 牌力桶 | 用户数 | 胜率 | 平均输赢 | 平均实际倍数 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 1 | A: 低牌力 | 1,466 | 87.31 | +1,654 | 8.09 |
| 1 | B: 中低牌力 | 1,997 | 93.14 | +2,014 | 9.19 |
| 1 | C: 中高牌力 | 2,069 | 91.16 | +2,135 | 10.07 |
| 1 | D: 高牌力 | 1,997 | 90.74 | +2,167 | 10.22 |
| 2 | A: 低牌力 | 1,801 | 66.69 | +822 | 8.64 |
| 2 | B: 中低牌力 | 1,665 | 82.82 | +2,148 | 12.59 |
| 2 | C: 中高牌力 | 1,742 | 90.93 | +3,145 | 14.55 |
| 2 | D: 高牌力 | 1,737 | **93.72** | +3,561 | 16.70 |
| 3 | A: 低牌力 | 1,983 | **60.46** | +446 | 9.64 |
| 3 | B: 中低牌力 | 1,435 | 81.18 | +2,227 | 13.13 |
| 3 | C: 中高牌力 | 1,606 | 89.10 | +3,351 | 16.31 |
| 3 | D: 高牌力 | 1,527 | **92.47** | +4,246 | 20.16 |

**牌力-胜率一致性的局序演化**（核心观察）：

- **第 1 局**：各牌力桶胜率 87%~93%，差仅 6pp，牌力对胜负影响弱；输赢绝对值也在 +1,654 ~ +2,167 区间
- **第 2 局**：低牌力 66.69% → 高牌力 93.72%，差 27pp，牌力开始显现决定性
- **第 3 局**：低牌力 60.46% → 高牌力 92.47%，**差 32pp**（最大值），且低牌力输赢均值降至 +446（仍为正但已大幅缩水）

**事实观察**：

- 第 1 局"好牌输"（D 桶 result_id=2）占比 9.26%；第 3 局"差牌赢"（A 桶 result_id=1）占比 60.46%——即"低牌力也能赢"在第 1 局是普遍现象，在第 3 局已大幅缩减
- 跨局序看，**牌力与胜率的一致性随保护配牌覆盖率下降而增强**：第 1 局 99.39% 保护 → 各桶胜率扁平；第 3 局 86.72% 保护 → 牌力桶间拉开

**第 1 局 新手保护 vs 非新手保护 对照**（`shuffle_type=201` vs 其他）：

| 保护类型 | 牌力桶 | 用户数 | 胜率 |
| ---- | ---- | ---- | ---- |
| 新手保护 | A: 低牌力 | 1,434 | 88.70 |
| 新手保护 | B: 中低牌力 | 1,991 | 93.27 |
| 新手保护 | C: 中高牌力 | 2,065 | 91.14 |
| 新手保护 | D: 高牌力 | 1,993 | 90.82 |
| **非新手保护** | A: 低牌力 | 32 | **25.00** |
| 非新手保护 | B: 中低牌力 | 6 | 50.00 |
| 非新手保护 | C: 中高牌力 | 4 | 100.00 |
| 非新手保护 | D: 高牌力 | 4 | 50.00 |

**注意**：非新手保护子组样本极小（46 人，4 个桶各 4-32 人），置信度低，仅作机制对照，不作推断依据。

## 七、明确不确定性

| 议题 | 现状 | 后续需要 |
| ---- | ---- | ---- |
| `hand_cards` / `bottom_cards` | **本报告窗口（06-18~24）手牌功能未上线**（上游"手牌上报"功能 06-25 早上才上线），故窗口内 0 覆盖，无法做手牌结构解析 | 07-01 后用 06-25~07-01 cohort 重跑手牌结构模块（实测 06-25 覆盖 92.5%，数据已可用） |
| `bomb_cnt` / `bomb_final` 字段 | 表文档未记录；机制含义（持有炸弹 / 算底牌后持有炸弹）由 JSON 结构推断 | 研发提供字段定义文档；确认王炸是否计入 |
| `is_pass`（是否重洗成功） | 本窗口三局全部 false，未触发重洗机制 | 扩大窗口或查 `shuffle_times != 0` 子集 |
| `role` 字段 | StarRocks 关键字，返回列名带反引号，已改别名 `player_role` 规避 | 持续留意 |
| 第 1 局非新手保护子组 | 仅 46 人，牌力桶间胜率波动大（25%/50%/100%/50%） | 置信度低，不可外推 |
| 第 2/3 局农民低牌力桶 | `avg_card_power` 接近 0（0.58/1.12），是真实低牌力还是字段缺失未确认 | 与研发确认 `card_power` 真实下限；可能与 `get_json_int` 失败有关 |
| 描述性 vs 因果 | 本报告仅描述事实与机制字段（`shuffle_type=201` 是新手保护），未做"为什么留存/流失"等因果推断 | 用户调研 / A/B 实验 |
| 渠道归一 | 渠道分布按 `channel_category_name`，含"官方(非CPS)"与"官方CPS"分项 | 业务侧确认是否需合并 |
